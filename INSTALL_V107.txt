V107 поверх V106:
1. Остановить бот.
2. Сделать копию .env и data/bot.sqlite.
3. Наложить patch V107 поверх V106.
4. Не заменять .env и data/bot.sqlite файлами из архива.
5. Запустить npm run verify (если зависимости установлены).
6. Запустить бот.
7. Выполнить owner-команду «тусы проверить». Старый verified snapshot будет автоматически признан устаревшим по версии dedupe.
8. Для физической очистки накопленных дублей использовать существующий workflow «тусы дубли проверить» → «тусы дубли применить».
