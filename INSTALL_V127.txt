V127 PATCH INSTALL (from V126)
1. Stop the bot.
2. Extract Gigorave_V127_patch_from_V126.zip into the V126 project root and overwrite files.
3. Start the bot again: pnpm dev (or npm run dev).
4. Open /pinball/. Assets use ?v=127 and no-store.

Pinball behavior:
- dashed ramps accept only intentional up-table shots;
- ramp exits continue along the visible curve instead of snapping back;
- a ramp exit cannot immediately trigger the opposite ramp;
- shooter-lane rollback/re-plunge from V126 remains intact.
