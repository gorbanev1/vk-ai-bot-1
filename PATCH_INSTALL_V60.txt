V60 — SELF-TARGET PARTICIPANT ROUTING GUARD

Установка поверх V59:
1. Остановить бота.
2. Сохранить .env и папку data.
3. Распаковать patch-архив V60 поверх каталога проекта с заменой файлов.
4. Выполнить: pnpm install --frozen-lockfile
5. Выполнить: pnpm verify
6. Запустить: pnpm dev

Новых переменных .env, зависимостей и миграций SQLite нет.
