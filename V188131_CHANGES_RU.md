# Изменения V188.131

1. Вход Astra больше не принимает слово «проект», «аудит», «проверь» за доказательство существования ZIP-вложения. Если архива нет, специальный обработчик возвращает `false`, оставляя запрос обычному GPT-маршруту. ZIP/TXT пути остаются разделены.
2. Роутинг архивного анализа понимает «Астра, проанализируй ZIP», но не запускает аудит без фактического ZIP и проверки owner DM.
3. Обычный текстовый ответ Telegram помечается фактически выбранным для завершённого API-вызова model ID, включая mini. В VK поведение mini не меняется.
4. Итоговая передача TXT и архивного результата сообщает подтверждённые в ходе операции model ID (если вызовы выполнялись в этом запуске).
5. Обновлены два устаревших теста обязательного ZIP и добавлены регрессионные тесты, включая проверку модели.
6. Остальные маршруты, таймауты и правила безопасности платных повторов сохранены из V188.130.
