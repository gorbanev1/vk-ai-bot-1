Gigorave Bot V145

1. Stop the bot.
2. Keep your existing .env and data/bot.sqlite; do not replace them with files from the archive.
3. Unpack V145 over V144, or apply the V144 -> V145 patch.
4. If needed: npm install
5. Start: npm start

Third recovery pass from the bot:
  Гигорейв третий обход моделей

Equivalent CLI command (preferably while the bot is stopped):
  npm run audit:third-recovery

The third pass does NOT rerun the whole full audit. It reads the latest completed report and only tests:
- keys left as uncertain after the full second key sweep;
- runtime modes that became healthy only on late retry rounds.

Default limits per uncertain key: 6 text candidates, 2 image candidates, 2 keys globally, exactly one active model probe per exact key.

Resume behavior: progress lives in THIRD_RECOVERY_SWEEP_V145/results.jsonl. If interrupted, run the same command again. Completed tasks are not repeated. A completed run is not repeated unless CLI is invoked with --force.

No-credit keys stay under the V144 quota lifecycle (5th/20th, delete after five confirmed no-credit passes). Restarts do not reset those counters.
