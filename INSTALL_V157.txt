Gigorave V157

1. Рекомендуется применить patch V156 -> V157 поверх рабочей V156 либо распаковать full-архив в новую папку.
2. Скопируйте рабочий .env, если используете новую папку.
3. Старый VK_CHAT_EVENT_CONVERSATIONS совместим. Для peer 2000000022 V157 сам выставляет auto-scroll=25, если четвёртое поле отсутствует.
4. При желании задайте четвёртое поле явно:
   Название|https://vk.ru/im/convo/2000000022|300|25
   Для бесед только с ручной прокруткой используйте |0.
5. Запустите npm install (если зависимости не установлены) и npm start.
6. Проверка основной беседы: Гигорейв парсер chat:2000000022.
