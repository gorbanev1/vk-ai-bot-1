УСТАНОВКА EVENTS V51

Сборка: events-v51-active-communication-master-switch
Базовая версия компактного патча: V50

1. Остановить Node-процесс бота.
2. Сохранить резервные копии .env, data/bot.sqlite и браузерного профиля.
3. Для полного архива распаковать V51 поверх проекта с заменой исходников.
   Для компактного архива сначала убедиться, что установлен полный V50.
4. Не удалять .env и data/. Эти файлы не входят в архив.
5. Выполнить:

   pnpm install --frozen-lockfile
   pnpm verify
   pnpm start

6. В логе проверить:

   [BOT PATCH] events-v51-active-communication-master-switch

7. Smoke test в группе:

   Гигорейв будь быдлом
   Гигорейв активное общение
   Гигорейв активное общение отключить
   Гигорейв статус активного общения

После отключения статус должен сообщить, что фоновые реплики выключены. В базе
next_outburst_at должен быть 0, а старые автоматические перепалки не должны
продолжаться. Явные обращения и команды боту должны отвечать как обычно.

Новые зависимости, переменные .env и миграции схемы не требуются.
