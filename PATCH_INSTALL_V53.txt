Установка Events V53 поверх V52

1. Остановите процесс бота.
2. Сделайте резервную копию проекта, .env, data/bot.sqlite и браузерного профиля.
3. Распакуйте архив патча поверх каталога V52 с заменой файлов.
4. Выполните:
   npm install
   npm run verify
5. Запустите:
   npm start

Миграция SQLite не требуется.
.env, data/ и авторизованный браузерный профиль в архив не входят.
