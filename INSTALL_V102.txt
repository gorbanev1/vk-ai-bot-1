INSTALL V102

1. Наложите файлы patch поверх V101.
2. Сохраните ваш существующий `.env` и `data/bot.sqlite`. Не заменяйте их из архивов.
3. Перезапустите бот.
4. При первом старте V102 SQLite одноразово обновит полный ответ `корды` и добавит строку: `Поддержать можно переводом по номеру телефона +79968257889 (Сбер).`
5. Проверка владельцем: отправьте `корды` или `координаты`; реквизиты должны идти после абзаца про добровольный донат.
