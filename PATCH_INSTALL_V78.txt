V78 — чистая AI-афиша + owner-ingest + Telegram image mode/quota

База: V77 (events-v77-roast-full-roster-name-only-fallback).

Установка:
1. Останови бот полностью (Ctrl+C) и убедись, что старый node --watch не остался запущен.
2. Сделай резервную копию проекта.
3. Распакуй содержимое VK_AI_BOT_V78_CUMULATIVE_PATCH поверх корня проекта:
   C:\Users\Adm\WebstormProjects\vk-ai-bot
4. НЕ удаляй и НЕ заменяй рабочие:
   .env
   data\
   data\bot.sqlite
   data\scraper-browser-profile\
5. В .env при желании явно укажи:
   TELEGRAM_GPT_IMAGE_DAILY_LIMIT=2
   Старый GPT_IMAGE_DAILY_LIMIT остаётся лимитом VK.
6. Запусти проверки:
   pnpm install --frozen-lockfile
   pnpm run check:syntax
   pnpm run check:imports
   pnpm run test:event-normalization
   pnpm run test:image-quota
   pnpm run test:help-context
   pnpm run test:telegram
   pnpm run test:command-routing
7. Запусти:
   pnpm dev

Ожидаемая сборка:
[BOT BUILD] events-v78-event-normalization-tg-image-mode-quota-owner-ingest

Быстрые проверки после запуска:
- Telegram: нажми «🖼 Изображение», затем отправь подряд два обычных описания — оба должны стать генерациями; режим остаётся активным.
- Вне режима напиши «рисуй ночной Воронеж» — запрос должен уйти в gpt-image-2.
- Обычный Telegram-пользователь: третья фактическая генерация/редактура gpt-image-2 за сутки должна получить лимит. Владелец — unlimited.
- «Гигорейв помощь» проверь отдельно в VK ЛС, Telegram ЛС, VK-конфе и Telegram-группе.
- «Гигорейв тусы эти выходные» — в анонсах не должно быть VIEW IN TELEGRAM, реакций, хэштегов, «Встреча/Действия», дублированных Когда/Что/Кто/Где/Почем или рекламных шуток в цене.
- Владелец: «добавить событие <ссылка>» — если на странице несколько постов, в логе должен быть [MANUAL EVENT PRIMARY POST], затем при наличии картинки [MANUAL EVENT IMAGE VISION].
