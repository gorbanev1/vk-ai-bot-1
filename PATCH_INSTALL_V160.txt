V160 hotfix install

Recommended over an existing V159/V158 working folder:
1. Stop the bot.
2. Extract the V160 patch over the current project folder, replacing files.
3. Run `pnpm install` only if your dependencies are not already installed (no new dependency is required).
4. Run `pnpm dev`.

The first launch automatically checks data/bot.sqlite. A malformed DB is copied to data/corruption-backups/<timestamp>/ before any destructive recovery action.

Do NOT manually delete the corrupt database before the first V160 launch if you want the automatic salvage attempt to have a chance to preserve readable rows.
