Gigorave V188.6 — exact VK bootstrap + poster date/time fusion

Version: 0.188.6
Base: V188.5

Fixes
1. Exact VK wall links no longer depend only on the rendered modal DOM when VK API hydration is unavailable. The browser reads the exact wall.getById object already embedded by VK in window.cur.apiPrefetchCache and recovers:
   - wall.date / publishedAt;
   - exact post text;
   - direct photo attachments;
   - canonical wall URL.
2. Yearless event dates such as "Когда: 3 октября" therefore get a reliable publication-date year anchor instead of being lost as date="".
3. Poster vision must emit fields on separate lines and copy printed numeric date/time exactly.
4. Model extraction is merged with deterministic local text+vision evidence. A valid deterministic eventDate/eventTime wins over a blank model field.
5. API and browser/bootstrap exact-post evidence are merged. If VK API has the text/date but browser bootstrap has the real wall photo (or vice versa), both survive.
6. The selected exact post photo is used for event image preparation instead of being discarded merely because an API post object existed.

Reproduced case
- https://vk.ru/wall-231705804_24
- post text: "Когда: 3 октября"
- poster: "03.10" and "18:00"
- post wall.date: 1788448080 (2026-09-03)
Expected fused result: 2026-10-03 18:00, venue КОТЕЛЬНАЯ.
