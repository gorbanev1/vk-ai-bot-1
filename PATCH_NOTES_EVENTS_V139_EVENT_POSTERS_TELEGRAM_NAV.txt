Gigorave Bot V139 — event posters + Telegram navigation
Build: events-v139-event-posters-telegram-navigation
Package: 0.139.0

WHY
1. VK public scraper could collect broad DOM media in visual order, so avatars, logos and UI icons could occupy the first image slots.
2. API-hydrated VK post photos were merged with DOM candidates, allowing irrelevant DOM media to survive beside the real poster.
3. Public VK output could send up to four event images, which exposed those bad candidates as a gallery.
4. Old event rows with no local imagePaths immediately received a generated card even when their exact VK wall post still contained a real photo.
5. Telegram main menu still exposed Pinball; action branches lacked a dedicated Back escape.

FIXES
- Added src/features/events/eventImageSelection.js with poster scoring/ranking and raster dimension detection.
- VK API post photo attachments are authoritative. DOM candidates are used only if API media is absent.
- Raw/rendered VK DOM extraction filters avatar/profile/emoji/reaction/sticker/icon/badge/logo UI media and ranks likely content media instead of taking the first four nodes.
- VK parser hash bumped to vk-playwright-local-v16-poster-ranking-v139 so previously processed posts are reconsidered on the next manual parser run.
- Event delivery picks exactly one best local poster for both VK and Telegram.
- If imagePaths are empty, exact VK wall URLs are rehydrated through wall.getById and the source photo is downloaded before a generated event card is used.
- Removed Pinball from Telegram menu/routing and disabled Pinball HTTP-server startup. Legacy source/data structures are retained non-destructively.
- Moved “➕ Предложить тусу” into the first Telegram main-menu row.
- Added “⬅️ Назад” to image/proposal/owner-add action states and event delete/restore menu; typed “назад” also exits pending state.
