# GIGORAVE V188.121 — Astra TXT/MD → текстовый ответ TXT

Это патч поверх работающей папки, не автономная сборка. Остановите бота, сделайте резервную копию и наложите файлы ZIP поверх текущей установки, **не удаляя** `.env`, `data`, SQLite-базы, `data/audit-jobs`, `src/index.js` и файлы, отсутствующие в патче. Затем запустите бот из обычной рабочей папки.

## Исправление

V188.120 рассматривала фразу `astra max` с упоминанием «проект»/«аудит» как команду аудита ZIP, даже если к сообщению прикреплён Markdown-файл с техническим контекстом, а пользователь просил анализ **текста** и результат TXT. Это приводило к ошибке «Получено вместо ZIP: .md; запрос к Astra не отправлялся».

Теперь в личной переписке владельца явный запрос Astra на анализ единственного `.md`/`.txt` (также `.markdown`, `.log`, `.json`, `.csv`, `.yaml`, `.yml`) с таким вложением перехватывается **до** ZIP-аудита и Word-генерации. Бот получает документ через Telegram, валидирует UTF-8, передаёт его содержимое обычным `input_text` в Astra Responses stream (`reasoningEffort=max`, `verbosity=high`, без `input_file`, `/files`, Base64, Code Interpreter и автоматического transport fallback). Результат модели локально оформляется в `GIGORAVE_ASTRA_MAX_CONTEXT_ANALYSIS.txt` и отправляется документом Telegram. Слова «ZIP», «проект», «аудит» **внутри задания на анализ текстового файла** не заменяют этот маршрут аудитом исходного ZIP.

Настоящий ZIP с запросом архивного аудита по-прежнему обрабатывается через TEXT MULTIPASS; явные команды Word без текстового вложения остаются доступны. Команда именно «аудит исходников ZIP» с прикреплённым не-ZIP без явного запроса анализа текстового файла по-прежнему сообщает об ошибке формата.

Ограничение: **один UTF-8 текстовый файл до 512 КиБ и 150 000 символов** за запрос; более крупный документ требует предварительного разбиения. Полный анализ может быть ограничен размером контекста/выходного ответа провайдера; локальный тест не доказывает реальную работоспособность роутера.

## Проверка

При запуске ожидайте `[BOT BUILD] V188.121`. Отправьте **один раз** небольшой `.md` или `.txt` документ с командой `Гигорейв astra max. Проанализируй прикреплённый текстовый файл и верни результат TXT.`

В логах должен появиться `[ASTRA TEXT ATTACHMENT] ... route=text-input-to-txt`, затем `[GPT ASTRA RESPONSES] ... files=0 stream=true` и `[AI RUNTIME TRANSPORT] ... preferred=stream`. В Telegram должен прийти TXT, а не DOCX и не ошибка «нужен ZIP». Для локальной проверки: `node --test tests/ai/v188121AstraTextAttachment.test.mjs tests/ai/v188120ArchiveVsWordRouting.test.mjs tests/ai/v188119TextDefaultRouting.test.mjs`.
