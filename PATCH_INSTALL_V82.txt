V82 — исправление автоматического импорта AI-ключей из parsed_secrets.txt

Проблема V81:
- переменная AI_SECRETS_IMPORT_DEFAULT_FILE была документирована, но сам импортёр её фактически не использовал;
- импортёр требовал путь аргументом;
- .env вычислялся от текущей рабочей папки, а не от корня проекта;
- pnpm dev не запускал импорт автоматически.

V82 исправляет всё это.

Установка:
1) Останови бота.
2) Распакуй V82 поверх проекта, сохрани существующие .env и data/.
3) Положи полный TruffleHog JSONL-файл ИМЕННО сюда:
   <project>\\parsed_secrets.txt
   <project>\\src\\
   То есть parsed_secrets.txt и src должны находиться рядом.
4) Запусти:
   pnpm dev

Теперь predev автоматически выполнит:
   node scripts/import-ai-secrets-from-trufflehog.mjs --auto --apply

Ручная проверка без записи:
   pnpm run import:ai-secrets -- ".\\parsed_secrets.txt"

Ручная запись:
   pnpm run import:ai-secrets -- ".\\parsed_secrets.txt" --apply

Важно:
- импортируются только OpenAI, Gemini, Anthropic, Groq, Hugging Face, NVIDIA;
- Stripe/GitHub/AWS/Cloudflare/SendGrid/JWT игнорируются;
- полный ключ в лог не печатается;
- перед изменением существующего .env создаётся backup;
- повторный запуск не дублирует уже импортированные секреты.
