УСТАНОВКА ПАТЧА НА WINDOWS

1. Остановите pnpm dev сочетанием Ctrl+C.
2. Распакуйте содержимое этого архива в корень проекта:
   C:\Users\Adm\WebstormProjects\vk-ai-bot
3. Согласитесь на замену существующих файлов.
4. Не заменяйте и не удаляйте свой рабочий .env.
5. Запустите:
   pnpm run test:private-errors
   pnpm run test:provider-diagnostics
   pnpm dev

КУДА ВСТАВИТЬ NVIDIA-КЛЮЧ

Откройте файл:
C:\Users\Adm\WebstormProjects\vk-ai-bot\.env

Найдите или добавьте строки:
NVIDIA_API_KEY=nvapi-ВАШ_РЕАЛЬНЫЙ_КЛЮЧ
NVIDIA_BASE_URL=https://integrate.api.nvidia.com/v1
NVIDIA_MODEL_DEFAULT=

Кавычки и пробелы вокруг значения не нужны.
Реальный ключ не вставляйте в .env.example, сообщения боту, Git или архивы.
