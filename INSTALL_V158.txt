Gigorave V158

1. Рекомендуется применить patch V157 -> V158 поверх рабочей V157 либо распаковать full-архив в новую папку.
2. Если используете full-архив в новой папке, перенесите рабочий .env. Durable auto-summary state остаётся во внешней user-level SQLite и не зависит от замены файлов релиза.
3. Запустите npm install, если зависимости ещё не установлены, затем npm start.
4. Для ручного парсинга закрытие всех управляемых окон Chromium теперь означает немедленную остановку запуска; уже собранные данные сохраняются.
5. Авторезюме поддерживает произвольное расписание, например: авторезюме 12 15 18; авторезюме 12:30, 18:00, 21:15; авторезюме статус все.
6. В Telegram доступны разделы изменения изображения и документов (DOCX/PDF/PPTX). Длинные задачи запускаются неблокирующе, меню остаётся доступным.
7. Для публичных VK/TG постов с несколькими анонсами V158 создаёт отдельные события и сопоставляет каждому его афишу по распознанному содержимому изображения.
