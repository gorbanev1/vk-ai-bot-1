EVENTS V43 — УСТАНОВКА ПАТЧА
================================

Патч накладывается поверх полного проекта V42 или полного проекта V41 с уже
установленным V42.

1. Полностью остановите bot/node --watch.
2. Сохраните копии:

   Copy-Item .env .env.backup
   Copy-Item data data.backup -Recurse

3. Распакуйте содержимое папки vk-ai-bot поверх текущего проекта с заменой файлов.
4. Выполните:

   pnpm install --frozen-lockfile
   pnpm verify
   pnpm dev

Ожидаемая строка запуска:

   [BOT PATCH] events-v43-targeted-roast-persona-intensity

Патч не содержит .env, рабочую SQLite-базу, data, node_modules или браузерный профиль.
