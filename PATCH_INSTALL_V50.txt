УСТАНОВКА EVENTS V50

Сборка: events-v50-flatter-command-message-metadata

Полный архив:
1. Остановить бота.
2. Сделать резервную копию проекта, `.env`, `data/bot.sqlite` и браузерного профиля.
3. Распаковать полный V50 с заменой исходников.
4. Выполнить `npm install` или `pnpm install`, если зависимости ещё не установлены.
5. Выполнить `npm run verify`.
6. Запустить бота.

Компактный патч:
1. Нужна чистая полная V49.
2. Распаковать patch-from-v49 поверх V49 с заменой файлов.
3. Выполнить `npm run verify`.

Миграция SQLite не требуется. `.env`, `data/`, токены и браузерный профиль в архив не входят.
