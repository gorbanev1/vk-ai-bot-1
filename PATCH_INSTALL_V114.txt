V114 patch over V113

1. Остановить бота.
2. Распаковать patch поверх V113 с заменой файлов.
3. Не удалять .env и data/bot.sqlite.
4. Запустить npm install (если зависимости ещё не установлены), затем npm start.
5. Старый data/event-verified-snapshot.json будет автоматически проигнорирован из-за новой версии dedupe-алгоритма.
6. Для пересборки постоянного verified snapshot владелец может выполнить команду «Гигорейв тусы проверить».
