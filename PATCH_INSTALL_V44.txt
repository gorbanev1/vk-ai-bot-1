УСТАНОВКА ПАТЧА EVENTS V44
===========================

Сборка: events-v44-vk-reply-quote-roast-day-window
Версия package.json: 0.44.0

Патч кумулятивный: его можно накладывать на полный проект V42 или V43.

1. Остановите работающий процесс бота.
2. Сохраните резервную копию data/bot.sqlite и .env.
3. Распакуйте содержимое папки vk-ai-bot из архива поверх корня полного проекта
   с заменой файлов.
4. Выполните:

   pnpm install --frozen-lockfile
   pnpm run test:roast
   pnpm run test:bot-addressing
   pnpm verify

5. Запустите бота и проверьте в тестовой VK-беседе:
   - прямое упоминание;
   - reply на сообщение бота без активной сессии;
   - пересылку/цитату сообщения бота;
   - «Гигорейв фас <имя>» без использования сообщений старше 24 часов.

Миграция SQLite не требуется.
