EVENTS V21 — ВСЯ БАЗА КОНФЫ, КОРОТКАЯ ПРАШНА И ТОЧНЫЕ TERRA/SOL
=================================================================

1. Вопросы про текущую беседу
-----------------------------
Если запрос явно относится к чату/конфе/кф/беседе/переписке/общению/диалогу
или распространённым сокращениям, бот читает ВСЕ сохранённые сообщения текущего
peer_id из SQLite. История делится на блоки и целиком обрабатывается базовой
моделью gpt-5.5. Сообщения считаются недоверенными данными, поэтому команды из
самой переписки не выполняются.

Для текстового запроса GPT формирует ответ строго по всей базе. Для запросов
«нарисуй», «проиллюстрируй», «визуализируй», «сделай картинку/арт/постер» базовая
GPT сначала обрабатывает всю историю в соответствии с запросом пользователя и
готовит визуальное описание; затем gpt-image-2 создаёт изображение.

2. Terra и самая продвинутая модель
-----------------------------------
Рабочие model id теперь заданы прямо в коде как надёжные значения по умолчанию. Если старый .env содержит модель не того семейства, бот пишет предупреждение и использует правильный fallback:
- default: gpt-5.5
- pro: gpt-5.6-luna
- pro2 / terra / терра: gpt-5.6-terra
- pro3 / sol / сол / «самая продвинутая модель»: gpt-5.6-sol

Режимы распознаются как отдельные полные токены до обычного pro. Для прашны:
- pro -> fast
- pro2 / терра -> balanced
- pro3 / самая продвинутая модель -> full

3. Короткая прашна
------------------
Интерпретация прашны теперь содержит два содержательных абзаца и строку
«Итог: ...». Модель выбирает только 3–5 решающих положений карты вместо полного
перебора домов, планет, панчанги и D-карт. Техническое предварительное сообщение
тоже сокращено.

4. Потоковые картинки
---------------------
Сохранена проверенная обработка gpt-image-2: SSE читается до [DONE], Markdown
`![Image](data:image/png;base64,...)` собирается даже при разбиении base64 между
чанками, после чего изображение проверяется и загружается во VK.

5. Проверки
-----------
- node --check для всех изменённых JS/MJS;
- тест текстового SSE/NDJSON;
- тест точных режимов pro/terra/pro3 и русских алиасов;
- тест распознавания запросов про текущую конфу и иллюстрацию;
- тест потоковой картинки с :PING, разбитым base64 и [DONE].
