# V188.105 — отложенные отчёты об ошибках вложений

Дата: 2026-09-18

## Изменено

- Немедленное сообщение `Не удалось обработать вложения. Ошибка записана в лог...` полностью удалено из media pipeline.
- Ошибка обработки вложения теперь молча ставится в долговечную очередь отчётов.
- Отчёт становится доступен через 3 часа после регистрации ошибки.
- Через 3 часа бот пишет подробную запись в `data/logs/attachment-failures/YYYY-MM-DD.jsonl` и отправляет владельцу личное сообщение.
- В личном сообщении указываются `reportId`, `requestId`, `operationId`, платформа, chat/message id, счётчики обработки, краткая причина, относительный и абсолютный путь к логу.
- Очередь хранится в `data/logs/attachment-failures/pending.jsonl`, поэтому рестарт процесса не теряет ожидающий трёхчасовой отчёт.
- При старте бот подбирает просроченные записи. Если ЛС владельцу временно недоступно, отправка повторяется через 15 минут; лог при этом не дублируется.
- Дополнительный minute-tick и точечный wake-up timer не блокируют завершение процесса (`unref`).

## Инвариант

Ошибка media/attachment pipeline больше не должна сама по себе писать предупреждение в исходный чат. Пользовательский чат продолжает основной сценарий по доступным данным; диагностический отчёт уходит владельцу отдельно через 3 часа.
