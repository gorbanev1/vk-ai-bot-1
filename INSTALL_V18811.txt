Gigorave V188.11 installation
=============================
1. Stop the bot.
2. Replace project files with the full-source archive.
3. Keep your current .env and data/ directory; they are not included.
4. Run pnpm install if dependencies are not already installed.
5. Start normally: pnpm start / npm start.

Event parser traces remain in:
  data/logs/event-parser/
  data/logs/event-parser/latest.jsonl

V188.11 adds exact VK raw-bootstrap recovery and bounded event-proposal AI
fallback; no new environment variables are required.
