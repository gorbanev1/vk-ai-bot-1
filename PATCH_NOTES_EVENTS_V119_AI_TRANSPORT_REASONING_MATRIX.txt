Gigorave V119 — AI transport + reasoning matrix audit
Date: 2026-08-24

Owner command:
  Гигорейв тест всех моделей

Fresh first pass
- AI_FULL_AUDIT_RESULTS is deleted at the beginning of a new full audit.
- A new timestamped directory is created from scratch.
- AUDIT_STATUS.json is updated while the audit runs.
- AUDIT_DONE.json is created when the transport/model audit finishes.
- Telegram receives progress messages and a final ✅ report.

Text/chat model matrix
- Every discovered text/chat key+model receives the same baseline prompt twice:
  1) non-stream
  2) real stream/SSE
- A stream test counts as stream only when the endpoint really returns a streaming content type and produces output chunks.
- Models that return ordinary JSON to stream=true are not falsely marked as streaming.

Runtime transport policy
- both OK: preferred=non_stream, fallback=stream
- stream only: preferred=stream, fallback=non_stream_retry_once
- non-stream only: preferred=non_stream, no failed-stream fallback
- both failed: removed from ai_runtime_modes after a successful full audit

Reasoning/intelligence matrix
- Levels: none, minimal, low, medium, high, xhigh, max.
- none is the exact baseline request without a reasoning parameter.
- Every other level is tested separately in BOTH non-stream and stream mode.
- The database stores supported reasoning levels and a preferred/fallback transport policy for every tested level.
- Main OpenAI-compatible runtime uses the reasoning-level-specific transport policy when available.

Image-generation matrix
- Each image model is tested using its normal provider image adapter.
- A separate real stream/SSE attempt is performed where an adapter exists.
- Stream-only image models remain enabled and are routed through stream first; non-stream can be used as fallback according to the learned policy.

Model classification
- guard/safeguard/moderation/content-safety catalog models are classified as moderation, not normal chat text models.

Secrets
- parsed_secrets.txt and its legacy variants are not parsed by runtime and are removed at startup (V118 behavior retained).
- .env is not rewritten by the audit. Failed key+model runtime combinations are removed from SQLite; source keys remain available for a later retry round.
