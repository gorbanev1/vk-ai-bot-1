# GIGORAVE V188.131 — Astra отвечает на текст без обязательного ZIP

Это готовый накопительный ZIP-патч **поверх конкретных ранее предоставленных V188.128, V188.129 или V188.130**. Новые исправления V188.131 включены вместе с прежним V188.130 (TXT/recovery и event quality): ставить отдельные архивы V188.129 или V188.130 перед этим не нужно. На произвольные более поздние/сильно изменённые версии без сравнения исходников не устанавливать.

## Что изменено

- В личном Telegram простое текстовое обращение «Астра, проверь ...», «Astra max аудит проекта ...» без приложенного ZIP идёт в обычную модельную маршрутизацию и **не требует архива**. Предусмотренный раньше автоматический отказ «пришли ZIP» для такого случая удалён.
- Если владелец сам прикрепил настоящий ZIP к явной Astra-команде аудита/анализа архива, срабатывает отдельный защищённый маршрут архивного аудита; TXT-файлы по-прежнему обрабатываются своим TXT-маршрутом.
- Текстовый ответ Telegram явно показывает идентификатор модели, выбранной для успешно выполненного AI-запроса; в частности, он виден и для базовой mini. Для обычных VK-реплик поведение мини-модели не меняется.
- В итоговой доставке TXT показывается модель задания и, если в этом запуске выполнялись AI-вызовы, выбранные модели этих запросов. В сообщениях с результатом архивного аудита выводятся идентификаторы моделей, подтверждённые в этом запуске.
- Это модель, **указанная в фактически выполненном запросе к AI-роутеру**. Если сторонний роутер скрыто переключает другую upstream-модель, подтвердить её без данных роутера бот не может.

## Установка

Не заменяйте код во время работы TXT-задания или скрейпера. Сделайте резервную копию проекта и каталогов `data/astra-text-jobs`, `data/telegram-text-transfer-logs`, `data/audit-jobs` и SQLite, остановите бот штатно. Распакуйте **всё содержимое этого ZIP в корень ранее предоставленного проекта** с заменой совпадающих файлов, но без удаления других. Базы данных, `.env`, пользовательские файлы и ключи в патч не включены. Затем запустите `npm run test:v188131` на изолированной тестовой копии и запускайте бот обычным способом.

На данный момент подключённый пользовательский компьютер недоступен, поэтому обновление не установлено в реально работающий экземпляр бота. Перед использованием на своей среде сравните пути установки и дождитесь окончания текущего задания.

## Контрольные примеры

- Без вложения: `Астра, объясни отличие SSE heartbeat от TCP keepalive` — текстовый ответ, без требования ZIP, с подписью модели.
- Без вложения: `Астра max, проверь код обработчика` — обычный запрос к Astra, без требования ZIP.
- С приложенным ZIP: `Астра max, аудит проекта по архиву` — прежний защищённый архивный маршрут, итоговый ZIP формируется самим ботом.
- С приложенным TXT: прежний специализированный маршрут, прогресс и журнал V188.130.

Профильные тесты не выполняют реальных платных AI-запросов или отправок Telegram. Код Cloudflare/AI-роутера этим изменением не затронут; самостоятельный SSE heartbeat на стороне роутера по-прежнему необходим при длительном молчании upstream.
