V63 — SCRAPER HELP AND RUN ALL

1. Команда «Гигорейв парсер» показывает локальную подсказку со всеми включёнными источниками и их точными идентификаторами.
2. Команда «Гигорейв парсер все» запускает все настроенные Telegram-, VK-public- и VK-chat-источники.
3. Поддерживаются варианты «парсер всё», «парсер запустить все» и «run all scrapers».
4. Все источники запускаются последовательно, чтобы несколько Playwright-задач не конфликтовали за общий браузерный профиль и память.
5. Итоговое сообщение показывает общий счётчик успешных и ошибочных источников и отдельный результат каждого источника.
6. Команды остаются owner-only; обычный пользователь получает «Команда недоступна.» до запуска парсинга.
7. Команды «парсер статус» и «парсер запустить <source-id>» сохранены.
8. Схема SQLite, .env и набор зависимостей не менялись.
