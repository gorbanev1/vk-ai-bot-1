V82 fixes the AI-key import regression from V81.

Root cause:
The V81 docs advertised a default secrets file next to src, but import-ai-secrets-from-trufflehog.mjs still required an explicit positional source path and resolved .env from process.cwd(). pnpm dev/start did not run the importer automatically.

Fix:
- project root is resolved from the script location;
- default source auto-discovery: <project>/parsed_secrets.txt;
- AI_SECRETS_IMPORT_DEFAULT_FILE is honored when present in .env;
- predev and prestart auto-import before the bot process starts;
- explicit source and explicit env path remain supported;
- JSONL and plain JSON array/object are accepted;
- redacted/placeholder secrets are rejected;
- duplicate existing values are skipped even when quoted in .env;
- exact source path, exact .env path, parsed record count and masked imported slots are logged;
- primary existing API key names are preserved;
- non-AI secrets remain ignored.
