V115 patch from V114

1. Stop the bot.
2. Back up the project directory and data/bot.sqlite.
3. Extract the V115 patch over the V114 project, replacing files.
4. Do not replace your .env or data directory.
5. Start the bot normally.

Telegram UX after deleting an event:
- "Вернуть тусу <название>" restores it.
- "🏠 На главную" exits the temporary deletion keyboard and restores the normal main menu.
