Gigorave Bot V132 — перенос истории удалённой беседы

1. Остановите бота.
2. Поверх V131 распакуйте patch V131 -> V132 с заменой файлов либо используйте full-архив.
3. НЕ удаляйте data/bot.sqlite — именно в нём находится старая история.
4. Запустите: pnpm dev
5. Добавьте бота в НОВУЮ групповую беседу.
6. Владелец бота прямо в новой беседе отправляет:

   Гигорейв привязать историю

Бот автоматически берёт самую активную сохранённую групповую беседу той же платформы, исключая текущую, создаёт SQLite backup и переносит её долговечную историю на peer_id новой беседы.

Для ручного выбора VK peer_id:
   Гигорейв привязать историю peer:2000000123

Переносятся:
- сохранённые messages;
- досье и дневные отметки досье;
- профили участников;
- список известных участников;
- interaction_memory;
- explicit_memories;
- постоянные настройки характера/активного общения.

Не переносятся намеренно:
- старые активные перепалки и таймеры;
- vk_chat_* данные парсера событий, потому что они относятся к URL старой удалённой беседы.

Если message_id новой беседы совпали со старыми, только конфликтующие ID новых сообщений безопасно перенумеровываются внутри SQLite. Старая история сохраняет исходные conversation_message_id.

Повторное выполнение для уже привязанной новой беседы блокируется журналом peer_history_migrations.
