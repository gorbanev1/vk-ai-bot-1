Gigorave Bot V142 — установка
=============================

Полный архив
------------
1. Остановить текущий бот.
2. Сохранить рабочие .env и data/bot.sqlite отдельно.
3. Распаковать V142 в новую папку.
4. Перенести свой .env и data/bot.sqlite.
5. npm install / pnpm install при необходимости.
6. Запустить бот.

Patch V141 -> V142
------------------
Остановить V141 и распаковать patch поверх каталога проекта с заменой файлов. .env и data/bot.sqlite патч не содержит.

Проверка API-ключей
-------------------
Owner-команда:
Гигорейв тест всех моделей

V142 сначала выполняет обычный provider-aware аудит, затем отдельно берёт каждый ключ с 0 рабочих runtime-моделей и повторно прогоняет его по всему известному набору text/image моделей. После этого подтверждённо нерабочие чужие ключи удаляются из .env.

Перед очисткой .env автоматически создаётся backup:
.env.before-ai-key-cleanup-<timestamp>.bak

Если во втором проходе у ключа только timeout/network/5xx, ключ автоматически НЕ удаляется.

Главный owner GPT endpoint OPENAI_COMPAT_API_KEY защищён и этой командой не тестируется/не чистится. Дополнительные исключения: AI_AUDIT_EXCLUDE_ENV_NAMES=name1,name2.
