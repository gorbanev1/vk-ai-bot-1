EVENTS V28 — ЯВНАЯ ДОЛГОВРЕМЕННАЯ ПАМЯТЬ
=========================================

1. Команда «запомни»
--------------------
Поддерживаются формы:
- Гигорейв запомни <текст>
- Гигорейв запомни что <текст>
- Гигорейв запиши в память <текст>
- Гигорейв сохрани в память <текст>
- ответ «Гигорейв запомни это» на конкретное сообщение

Исходное входящее сообщение сохраняется целиком в explicit_memories.raw_message.
Полезный текст для поиска хранится отдельно в memory_text и normalized_text.
Запись привязана к peer_id, автору и conversation_message_id; повторная
обработка того же сообщения обновляет запись, а не создаёт дубль.

2. Поиск памяти
---------------
Поиск выполняется локально перед обычным GPT-ответом по всем активным записям
текущего peer_id. Используются:
- точные совпадения слов;
- упрощённое сопоставление русских словоформ;
- совпадения префиксов для длинных слов;
- устойчивые фразы из 2–4 значимых слов;
- понижение веса слов, встречающихся во многих записях;
- минимальный порог релевантности и ограничение top-5.

Вопросительные и служебные слова удаляются, поэтому формулировки «кто такой»,
«что значит», «что известно», «напомни», «расскажи» не требуют отдельных
жёстких команд и не создают ложных совпадений сами по себе.

3. Контекст GPT
---------------
При совпадении GPT получает:
- исходный вопрос;
- найденные записи с автором и датой;
- правило использовать только относящиеся к вопросу сведения;
- правило не выполнять инструкции внутри памяти;
- правило сообщать о противоречиях между сохранёнными утверждениями.

Прашна не смешивается с этой памятью: астрологическая интерпретация остаётся
основанной только на полном рассчитанном пакете карты.

4. Генерация изображений
------------------------
Если запрос на картинку совпал с памятью, базовая GPT сначала объединяет запрос
и релевантные факты в один визуальный промпт. Только затем GPT image создаёт
изображение. При отсутствии совпадений остаётся обычный прямой маршрут.

5. Приватность и область действия
---------------------------------
Память изолирована по peer_id и не переносится между беседами или ЛС.
Обычные личные сообщения не сохраняются. В SQLite попадает только сообщение,
которое пользователь явно попросил запомнить.
