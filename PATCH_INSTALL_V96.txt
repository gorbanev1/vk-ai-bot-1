Ожидаемая сборка:
[BOT BUILD] events-v96-chat-repost-vision-live-verified-events-cache

ВАЖНО: V96 НЕ запускает полную проверку/дедупликацию тус при старте бота.
Первый раз после обновления вручную выполни:

Гигорейв тусы проверить

Команда делает тяжёлый проход один раз:
raw events -> GPT normalization -> deterministic/two-contour dedupe -> GPT только для спорных пар/слияния -> compact summaries -> data/event-verified-snapshot.json

После этого обычные запросы работают из готового snapshot без AI-проверки на каждый запрос:

Гигорейв тусы август кратко
Гигорейв тусы сентябрь кратко

Парсеры:

Гигорейв парсер все
Гигорейв парсер chat:2000000022

Для VK-беседы:
- вкладка открывается один раз;
- автоматический backfill идёт небольшими порциями примерно по 10 сообщений;
- после каждого движения ждётся lazy-media;
- текст репоста, вложенные wall/copy_history и изображения дополнительно гидратируются через VK API;
- image-only сообщение тоже проверяется vision-моделью;
- live monitor работает всё время, пока вкладка открыта;
- если прокрутить чат вручную через час или через день, новые увиденные сообщения будут поставлены в очередь разбора;
- парсинг беседы считается завершённым ТОЛЬКО после закрытия вкладки (или явной команды остановки);
- после закрытия вкладки бот дожидается очереди сообщений; если это последняя активная VK-беседа, автоматически запускается полный verification/update snapshot; если другие беседы ещё открыты, проверка откладывается до последней.

Для публичного VK/Telegram:
- после завершения ручного прохода автоматически обновляется verified snapshot.

Проверка reply/repost vision:
1. В VK-беседе ответь на сообщение, внутри которого репост VK-поста с афишей.
2. Напиши: Гигорейв что на изображении
3. Бот должен гидратировать reply, затем nested wall/copy_history и передать найденные картинки vision-модели.
