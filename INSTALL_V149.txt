V149 INSTALL
============

Full archive:
- Keep your existing `.env` and `data/` directory.
- Replace application files with V149.
- Do NOT overwrite `data/bot.sqlite`.
- Start the bot normally.

Patch V148 -> V149:
- Stop the bot.
- Apply patch files over V148.
- Keep `.env` and `data/` unchanged.
- Start the bot.

SQLite soft migrations add active_chat_interval and active_chat_target_offset automatically.
No manual SQL is required.
