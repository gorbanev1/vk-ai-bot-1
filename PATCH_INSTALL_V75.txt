УСТАНОВКА НАКОПИТЕЛЬНОГО ПАТЧА V75

База: V66–V74. Архив накопительный и включает изменения V67–V74.

1. Остановите бота: Ctrl+C.
2. Сделайте резервную копию проекта.
3. Распакуйте содержимое папки VK_AI_BOT_V75_CUMULATIVE_PATCH поверх:
   C:\Users\Adm\WebstormProjects\vk-ai-bot
4. Согласитесь на замену файлов.
5. НЕ удаляйте и НЕ заменяйте:
   .env
   data\
   data\bot.sqlite
   data\scraper-browser-profile\
6. Выполните:
   pnpm install --frozen-lockfile
   pnpm run test:command-routing
   pnpm verify
   pnpm dev

Ожидаемая строка запуска:
[BOT BUILD] events-v75-command-routing-audit-priority-lock

Проверка в VK от владельца:
Гигорейв маршрутизация проверить

Проверка конкретной команды:
Гигорейв маршрут pro3 nvidia проверить
Гигорейв маршрут pro3 прашна Москва вопрос
Гигорейв маршрут pro3 тусы на этой неделе

В первом случае ключ pro3 будет отмечен как неприменимый к служебной
NVIDIA-команде, но маршрут provider сохранится. Во втором ключ применяется
к GPT-прашне. В третьем локальная команда афиши сохранится, а ключ будет
явно отмечен как неприменимый к детерминированному запросу SQLite.
