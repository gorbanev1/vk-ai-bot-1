EVENTS V25 — ССЫЛКИ ИЗ СООБЩЕНИЙ БЕСЕД
======================================

1. Для событий sourceType=vk_chat ссылка на саму беседу больше не создаётся.
2. В sourceUrl сохраняется только первая обычная HTTP(S)-ссылка из исходного
   сообщения.
3. Любые VK URL раздела /im и /im/... отбрасываются как персональные.
4. Если подходящей ссылки нет, итоговое сообщение содержит строку:
   Информация с беседы
5. Защита применяется и при выводе старых записей базы, где source_url уже
   содержит ссылку вида vk.ru/im/convo/...?... .
6. Ссылки автора/аватара отфильтровываются при чтении DOM.
7. Добавлены тесты маршрутизации источника события.

Проверка:
- node --check src/index.js
- node --check src/vkChatEventScraper.js
- node --check src/vkChatEventSource.js
- npm test
