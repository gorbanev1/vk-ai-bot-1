УСТАНОВКА EVENTS V49

Сборка: events-v49-pro-two-page-contract
Базовая версия: полный V48

1. Остановить бота.
2. Сделать резервную копию проекта, .env, data и браузерного профиля.
3. Распаковать V49 поверх полного V48 с заменой файлов.
4. Выполнить npm install или pnpm install, если зависимости ещё не установлены.
5. Выполнить npm run verify.
6. Запустить npm start.
7. Во VK и Telegram отправить один и тот же запрос вида:

   Гигорейв pro3 напиши подробное эссе на 10000 слов о тестовой теме

8. Проверить, что бот не спорит о длине, не предлагает другой формат и выдаёт
   законченный ответ объёмом не более двух больших страниц. Если текст разделён,
   все части должны оставаться reply к исходному сообщению.

Миграция SQLite не требуется.
Новых переменных .env и зависимостей нет.
.env, data, bot.sqlite и браузерный профиль в патч не входят и не должны
перезаписываться.
