Gigorave V188.32 installation / verification

1. Replace the previous project with this V188.32 build while preserving your real .env, data directory and browser profile/session as usual.
2. Install dependencies with the Node.js version required by package.json.
3. Run: npm run test:v18832
4. Start the bot normally.
5. Run the parser flow that includes VK chat peer 2000000022.
6. Watch for logs similar to:
   [VK CHAT PARSER PASS] peer=2000000022 pass=pass1-exact ...
   [VK CHAT PRIORITY INITIAL SNAPSHOT] ...
   [VK CHAT PRIORITY BACKFILL] ... loadedOlder=.../50
7. If VK changes its DOM, the parser should automatically move to pass2-adaptive or pass3-heuristic; the log will show which one was selected.

The priority chat intentionally scrolls upward slowly and does not accept one temporary scrollTop=0 as the end of history.
