УСТАНОВКА ПАТЧА V64 ПОВЕРХ V63

1. Остановите бота.
2. Сделайте резервную копию .env и папки data.
3. Распакуйте содержимое patch-архива поверх проекта V63 с заменой файлов.
4. Выполните:
   pnpm install --frozen-lockfile
   pnpm verify
5. Запустите:
   pnpm dev

Новых npm-зависимостей, переменных .env и миграций SQLite нет.

Проверка команд:
- Гигорейв парсер
- Гигорейв парсер tg:kurazhcity
- Гигорейв парсер все

Если Telegram API недоступен при старте, VK продолжит работать, а фоновые Telegram-выкрики будут пропускаться без GPT-запросов и сетевых ошибок.
