Gigorave V188.57 — установка

1. Полностью остановить текущий Node-процесс.
2. Не удалять data/, data/healthy-backups/ и data/corruption-backups/.
3. Распаковать полный архив поверх проекта либо применить patch-from-V18856.
4. Запустить npm install только если обычно это делаете; зависимости не менялись.
5. Запустить npm run start / node src/index.js.

На первом старте V188.57 старый count-only history checkpoint будет признан legacy.
Ожидаемый лог:
  [VK HISTORY LOCAL SQLITE RESCAN] ... reason=legacy-or-invalid-checkpoint
  [VK HISTORY LOCAL SQLITE] file=... rows=...
  [VK HISTORY LOCAL SQLITE DONE] ... checkpoint=v2

После этого повторный старт без изменений snapshots должен дать:
  [VK HISTORY LOCAL SQLITE SKIP DURABLE] ... checkpoint=v2

Чтобы принудительно сверить доступную историю VK с самого начала, владелец может отправить в нужной беседе:
  Гигорейв подтяни историю с самого начала

Эта команда не удаляет существующие строки и добавляет только отсутствующие incoming messages.
