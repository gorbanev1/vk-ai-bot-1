# V188.141 — исправление регрессии «парсер всё» и запись DOM без добавочного скролла

* Удалена добавленная V188.140 вторая прокрутка `prepareVkFinalDomCapture` из путей VK public / VK chat / Telegram HTML. Штатные конечные проходы и очередь источников сохранены.
* При штатном чтении VK DOM берётся HTML, уже требующийся парсеру: исходный checkpoint, затем по изменению спустя >=10 секунд или увеличению размера >=30%, максимум 12 на источник. Вне очередного штатного чтения новые запросы к вкладке не создаются.
* `latest.dom.raw.html` заменяется целиком атомарно; `dom.raw.html` сохраняется из конечного состояния той же вкладки. На незавершённом проходе остается последний checkpoint.
* Проверка контрольных сумм распространяется на промежуточные версии. Добавлен отдельный offline-тест имитации двух наблюдений, увеличения DOM, финального чтения и отсутствия второго скролла.
