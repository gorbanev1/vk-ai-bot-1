V66 исправляет ошибочную выдачу ответов про организаторскую тусу на обычные личные вопросы.

Причина: семантический GPT-классификатор запускался для каждого личного сообщения и иногда ошибочно возвращал party_date/party_format/party_info. Теперь FAQ активируется только локальной детерминированной проверкой явного предмета вопроса и поддерживаемого намерения.

Добавлены owner-only команды:
- api
- api openai проверить
- api nvidia проверить
- api openai модели [фильтр]
- api nvidia модели [фильтр]
- api openai тест <model>
- api nvidia тест <model>
- api openai запрос <model> <текст>
- api nvidia запрос <model> <текст>

Ключи берутся только из .env и не выводятся в сообщения или логи.
