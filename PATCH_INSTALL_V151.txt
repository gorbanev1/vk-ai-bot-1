PATCH V150 -> V151
==================

Требуется чистый Gigorave V150.

1. Остановить бота.
2. Сделать резервную копию рабочей папки и data/bot.sqlite, если база существует рядом с развернутым проектом.
3. Распаковать содержимое patch-архива в корень V150 с заменой файлов.
4. Установить/обновить зависимости штатной командой проекта.
5. Выполнить npm run verify.
6. Запустить npm start.

Patch не содержит data/bot.sqlite и не должен перетирать пользовательскую базу. Новые fingerprint-колонки добавляются мягкой SQLite-миграцией при запуске.
