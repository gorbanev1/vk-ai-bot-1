GIGORAVE V106 — coords requester broadcast

1. Наложите patch поверх V105 Dual VK (или используйте полный sanitized source).
2. Сохраните свой .env и data/bot.sqlite. Не заменяйте их файлами из архива.
3. Новых переменных .env для V106 не требуется.
4. Запустите npm run verify или npm test.
5. После запуска таблица coords_request_recipients создастся автоматически в существующей SQLite.

- корды получатели
- корды список
- корды рассылка
- корды рассылка отправить
