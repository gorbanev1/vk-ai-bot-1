V74 — NVIDIA Image Timeout Grace

1. Остановить бота: Ctrl+C
2. Скопировать содержимое архива поверх корня проекта:
   C:\Users\Adm\WebstormProjects\vk-ai-bot
3. Не заменять и не удалять .env и data\
4. Выполнить:
   pnpm install --frozen-lockfile
   pnpm run test:nvidia-image
   pnpm run test:provider-diagnostics
   pnpm dev

Ожидаемая строка:
[BOT BUILD] events-v74-nvidia-image-timeout-grace

Новые значения по умолчанию:
NVIDIA_IMAGE_ATTEMPT_TIMEOUT_MS=360000
NVIDIA_IMAGE_TOTAL_TIMEOUT_MS=1200000

Если эти переменные уже явно записаны в рабочем .env, код не перезапишет их. Чтобы применить новые значения, измените их вручную либо удалите старые строки и перезапустите бота.

Старый NVIDIA_IMAGE_TIMEOUT_MS продолжает работать как псевдоним общего бюджета команды.

Проверка:
Гигорейв nvidia нарисуй ночной Воронеж в стиле киберпанка

Серверный HTTP 504/5xx не ждёт истечения клиентского лимита: после ответа NVIDIA бот сразу переходит к следующей модели.
