Events V54 — universal image analysis

1. Добавлен отдельный vision-маршрут. Команды «что на картинке», «что изображено», «опиши/оцени/проанализируй фото», «прочитай текст на картинке» и «предложи варианты» больше не смешиваются с генерацией gpt-image-2.
2. Изображения извлекаются из текущего сообщения и штатного reply, а также рекурсивно из VK wall, wall_reply, copy_history, пересланных сообщений и вложений photo.
3. Для VK выбирается наибольший доступный размер каждой фотографии, а не несколько дубликатов одной картинки.
4. Для Telegram поддерживаются photo, image-document, animation и sticker thumbnail. Бот получает file_path через getFile и передаёт изображение vision-модели.
5. При reply изображение из исходного сообщения имеет приоритет над изображениями текущей команды.
6. По умолчанию анализ выполняет pro2 / gpt-5.6-terra. Явные ключи pro, pro2, pro3, gpt54 и gpt55 сохраняются. GPT_VISION_MODEL позволяет указать точный model id.
7. Модель получает изображения как мультимодальный content image_url в /v1/chat/completions. Закрытые Telegram-файлы и доступные VK-файлы предварительно скачиваются и передаются data URL.
8. При временном отказе запрос повторяется через 5–30 секунд; после второго отказа выбирается следующая более сильная модель. Для Terra это Sol.
9. Текст и инструкции внутри изображения считаются недоверенными данными и не могут подменить системный промпт.
10. Vision-запросы используют обычную дневную квоту выбранной текстовой модели и возвращают квоту при ошибке.
11. Добавлены тесты маршрутизации, извлечения изображений из VK/Telegram и fallback на неподдерживаемой vision-модели.

GPT Image 2 остаётся отдельной моделью генерации. Он не используется для распознавания и описания входящих изображений.
