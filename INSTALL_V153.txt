GIGORAVE V153 — INSTALL

1. Остановить текущий процесс бота.
2. Сделать резервную копию папки data/.
3. Распаковать V153 поверх V152 либо использовать patch V152 -> V153.
4. Не удалять data/: SQLite registry добавленных владельцем источников должен сохраниться.
5. Выполнить npm install / npm ci в соответствии с вашим текущим способом установки.
6. Запустить на Node >=24.

Быстрая проверка исправления:
- отправить: Гигорейв парсер vk:<источник>
- прокрутить рабочую вкладку;
- закрыть вкладку или всё окно Chromium;
- сразу отправить боту: тусы

Ожидается: бот отвечает сразу; парсер считает закрытие штатным концом, сохраняет уже собранное, не запускает retry/recovery и Chrome сам повторно не открывается.
