V89 — single-pass scraper tab persistence

1. Останови бота.
2. Распакуй V89 поверх текущего проекта.
3. НЕ заменяй свой .env, data/, SQLite DB и browser profile.
4. Установи зависимости (если package manager просит):
   pnpm install --frozen-lockfile
5. Запусти:
   pnpm dev
6. Проверь сборку:
   [BOT BUILD] events-v89-single-pass-scraper-tab-persistence
7. В боте от владельца:
   Гигорейв парсер все

Ожидаемое поведение:
- каждый успешный VK/Telegram источник открывается один раз;
- та же вкладка используется для парсинга и остаётся открытой;
- второй проход запускается ТОЛЬКО если первая попытка реально упала;
- для Telegram открытой остаётся latest-вкладка; страницы ?before=... для пагинации закрываются;
- VK-беседы по-прежнему открываются один раз и остаются ручными.
