Gigorave V188.36 — auditable parser pipeline

Key changes
- Every manual parser run saves the complete DOM snapshot before exact parsing.
- VK Messenger virtual-scroll runs also save every relevant DOM window so old messages can be reproduced later.
- Exact parser consumes the same HTML snapshot that was written to diagnostics; adaptive/heuristic passes are compared against it.
- Per-source parser-report.json records exact/adaptive/heuristic counts, IDs, failure reasons, fallback-only items and prefilter decisions.
- run-manifest.json links trace, DOM snapshots, raw caches and parser reports for one run.
- Interrupted VK public capture attempts to persist the last known full DOM and records the capture failure reason.
- Candidate prefilter is auditable: score, reasons, evidence, DB match, trash/AI decision.
- Existing announcements are checked before AI when canonical source/exact source text already maps to a saved event.
- Manual parser uses a global priority limiter. Strong future candidates with date/time/venue/repost/poster outrank old/noisy messages.
- AI trace records queue wait, limiter slot, model/mode/provider, attempt, duration, retry/rotation/escalation and result/error without secrets.
- Parser AI calls use a bounded per-attempt timeout and the configured model ladder default -> gpt54 -> gpt55 -> pro -> pro2 -> pro3.
- AI extraction/vision no longer receives an outer 5-pass event retry on top of the internal model failover; the external wrapper is single-attempt for these operations.
- The 10-minute parser-all threshold remains a soft owner-status boundary; background processing is not killed by it.
- Parser-all invalidates stale event display/image caches and writes run verification/visibility diagnostics so DB-present-but-not-shown events can be diagnosed.

Observed live-DOM issue addressed
- CMID 5040 style messages (forward -> AttachWallNew -> AttachWallNew__message -> wall link -> PhotoItem__img) are treated as strong structural candidates without hardcoding the message ID or event name.
- UI timestamps, avatars, emoji/reaction images and wrapper text do not by themselves promote a message to AI.

Runtime diagnostics

- trace.jsonl
- run-manifest.json
- *.dom.html
- *.raw-cache.json
- *.parser-report.json
- run-verification*.json (when verification is produced)

Release ZIP intentionally excludes runtime data, databases, logs and secrets.
