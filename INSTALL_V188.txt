Gigorave V188 installation
==========================

PATCH route (recommended when V187.2 is installed)
1. Stop pnpm dev / the bot process.
2. Back up the project directory.
3. Extract Gigorave_V188_patch.zip into the project root with overwrite enabled.
4. Do NOT delete or replace .env, data/, bot.sqlite, bot.sqlite-wal or bot.sqlite-shm.
5. Run pnpm install only if your normal workflow requires it; V188 adds no new npm dependency.
6. Start: pnpm dev
7. Confirm:
   [BOT BUILD] events-v188-hierarchical-chat-memory-weekly-monthly
   [BOT PATCH] events-v188-hierarchical-chat-memory-weekly-monthly

On the first V188 start, hierarchical history bootstrap can legitimately make GPT calls: this is the requested one-time indexing pass. Its durable state is external to bot.sqlite. Later restarts must reuse that state instead of rebuilding unchanged history.

Command semantics:
- “Гигорейв резюмируй за день” = from 06:00 Europe/Moscow to now.
- “Гигорейв резюмируй за сутки” = rolling 24 hours.
- “Гигорейв резюмируй за неделю” = rolling 7 days.
