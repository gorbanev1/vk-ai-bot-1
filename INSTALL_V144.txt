Gigorave Bot V144

1. Остановить бота.
2. Сохранить текущие .env и data/bot.sqlite. Не заменять их пустыми файлами.
3. Распаковать V144 поверх V143 или применить patch V143 -> V144.
4. При необходимости: npm install
5. Запуск: npm start

Команда «Гигорейв тест всех моделей» выполняет финальный полный аудит. Валидные ключи без денег/кредитов не удаляются: они переносятся в отдельный закомментированный блок GIGORAVE AI QUOTA QUARANTINE в .env.

Карантинные ключи перепроверяются ровно 2 раза в месяц: 5-го и 20-го числа, Europe/Moscow. Только подтверждённый quota/no-credits увеличивает счётчик. Network/timeout/5xx счётчик не увеличивают. После 5 подтверждённых quota-проходов ключ удаляется.

Счётчик, последний завершённый календарный слот и история состояния хранятся в SQLite maintenance_state. Перезапуск/обновление бота не сбрасывает счётчик и не создаёт повторный проход в том же календарном слоте. Если ключ ожил — он возвращается из закомментированного блока в активный .env и снова добавляется в runtime registry.
