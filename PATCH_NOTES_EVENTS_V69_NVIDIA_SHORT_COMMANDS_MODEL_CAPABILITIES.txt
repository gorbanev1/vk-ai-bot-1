V69 — NVIDIA Short Commands and Model Capabilities

База: V68 events-v68-nvidia-account-model-probe-fulltest.
Новая сборка: events-v69-nvidia-short-commands-model-capabilities.

Исправлено
1. Короткие команды «Гигорейв nvidia», «Гигорейв нвидиа» и «Гигорейв энвидиа» теперь перехватываются до обычного GPT-router.
2. Голая команда NVIDIA больше не вызывает ответ gpt-5.4-mini с уточняющим вопросом.
3. Короткие NVIDIA-команды работают в compact-режиме без промежуточных диагностических сообщений.
4. Добавлен естественный запрос полного каталога:
   «Гигорейв nvidia доступные по этому апи ключу модели с описанием возможностей каждой».
5. Для каждой модели из GET /models формируется краткое описание назначения:
   chat/instruct, reasoning, code, vision/multimodal, embeddings, rerank, safety, detector, parser, translation, domain model и т. п.
6. В описании отдельно указано, является ли модель обычной chat/completions-моделью или требует embeddings/ranking/специализированного endpoint.
7. Сохранена честная граница: присутствие в GET /models подтверждает видимость модели ключу, но не гарантирует доступ к конкретной serverless-функции; реальный POST проверяет команда «рабочая модель».
