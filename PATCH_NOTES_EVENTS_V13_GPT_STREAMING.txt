EVENTS V13 — потоковые GPT-запросы без ожидания полного JSON
=============================================================

1. Все текстовые обращения к OpenAI-compatible /v1/chat/completions теперь
   отправляются с stream=true и заголовком Accept: text/event-stream.
2. SSE-чанки читаются сразу по мере поступления до события [DONE].
3. Поддержаны два распространённых формата:
   - choices[0].delta.content;
   - Responses API: response.output_text.delta и response.completed.
4. Пробелы между потоковыми чанками сохраняются, поэтому слова не склеиваются.
5. Поддержан резервный поток NDJSON/JSON-seq.
6. Если сервер игнорирует stream=true и возвращает обычный JSON, сохраняется
   обратная совместимость с прежней обработкой.
7. Генерация изображений через chat/completions также использует stream=true.
   Из потока выбирается самый полный base64-вариант или итоговая URL-ссылка.
8. Для текста установлен клиентский предел 15 минут, для изображения — 20 минут.
   При регулярно поступающих чанках Cloudflare не должен считать соединение
   бездействующим и обрывать его по Proxy Read Timeout.
9. Переменная OPENAI_COMPAT_STREAM=0 позволяет временно вернуть обычный JSON.
10. Добавлен отдельный модуль src/openAIStream.js без накопления сырого потока
    целиком в памяти.

ПРОВЕРКА
- node --check выполнен для всех JS-файлов.
- SSE Responses API и NDJSON проверены локальным потоковым тестом.
- Реальный запрос к router.cheap не выполнялся: API-ключ в патч не включён.
