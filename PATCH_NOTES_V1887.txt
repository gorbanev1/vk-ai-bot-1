Gigorave V188.7 — strict participant matching + exact summary schedule + resilient VK event evidence

Version: 0.188.7
Base: V188.6

Fixes
1. Participant name resolution now requires strictly more than 80% similarity for at least one name/nickname part. Exactly 80% is rejected; the reproduced `связь` -> `Святой ...` false match is covered by a regression test.
2. Project identity bridge: standalone `Тимасин` / `Тимофей` resolves to the two known profiles `Тимофей Тимофеев` and `Тимасин Тимасинский`. Explicit different full names are not swallowed by that bridge.
3. Participant-focused summaries use the entire linked VK history, not a trailing message stub. The pipeline combines the target's own messages with all qualifying mentions from others, takes ±10-message context around every mention, merges overlapping windows, then asks AI to remove unrelated branches before the final synthesis.
4. Bare or unclear `резюмируй` returns a usage hint. The old implicit "last 100 messages" behavior is gone. Rolling time ranges are no longer silently clipped to MAX_MESSAGES.
5. Weekly hierarchical results can be sent only Sunday at 20:00 Europe/Moscow. No Monday/Tuesday restart catch-up.
6. Monthly hierarchical results can be sent only at 20:00 on the final calendar day. The covered interval is day 1 00:00 -> final day 20:00; no next-month catch-up.
7. VK event/community pages get a structured-data first pass that recursively scans available bootstrap/runtime objects for event semantics and a start timestamp. It tolerates key/method shape changes instead of requiring one literal source snippet. If unavailable, normal DOM/meta/body/post/image parsing remains the fallback.
8. For the reproduced VK event payload `club239795426`, `start_date=1789833600` deterministically yields `2026-09-19 19:00` Europe/Moscow before AI extraction.

Regression tests
- npm run test:v1887
- legacy V188 summary/hierarchy tests and V188.6 event temporal-fusion regression are also run before packaging.

Operational data (.env, browser profiles, bot.sqlite, WAL/SHM and journals) is not included in release archives.
