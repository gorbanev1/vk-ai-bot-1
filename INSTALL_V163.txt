GIGORAVE V163

If you are currently on V161 and did NOT install V162:
- use Gigorave_V163_patch_V161_to_V163.zip directly over the current bot folder.
- do not delete your data directory or persistent user state.

Alternatively unpack Gigorave_Bot_V163_full.zip over the application code.
The full archive intentionally contains no data/bot.sqlite, so it does not
replace the working database.

Then run:
  pnpm dev

Checks inside the chat:
  активное общение статус
  активное общение 3

After three ordinary eligible chat messages the mode must make one autonomous
reply somewhere inside that 3-message window. Status now shows the runtime
attempt/model/error if something external fails.

V163 includes V162 auto-summary fixes as well.
