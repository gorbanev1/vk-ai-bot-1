УСТАНОВКА EVENTS V46
====================

Сборка: events-v46-local-maximum-astrology-audit

1. Остановить бота.
2. Скопировать отдельно .env и папку data/.
3. Распаковать V46 поверх полного проекта V45 с заменой файлов.
4. Не заменять своей рабочей копией файлы из data/ и не переносить чужой .env.
5. Выполнить:

   pnpm install --frozen-lockfile
   pnpm verify
   pnpm dev

Для максимальной точности локальной астрологии:

- скачать совместимые файлы Swiss Ephemeris *.se1;
- указать папку в EPHEMERIS_PATH;
- при необходимости строгого отказа от Moshier поставить
  ASTROLOGY_REQUIRE_SWISS_FILES=1.

Smoke test:

   Гигорейв pro3 прашна локалэфемериды Воронеж <вопрос>
   Гигорейв pro3 натал локал 14.03.1987 19:40 Воронеж подробно

В логах ожидаются packet=maximum, auditComplete=true и
precision=swiss-files-confirmed либо явно обозначенный
precision=moshier-or-mixed-fallback.

Миграция SQLite не требуется.
