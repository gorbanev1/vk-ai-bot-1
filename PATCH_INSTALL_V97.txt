Установка V97 поверх текущего проекта
======================================

1. Остановите единственный запущенный процесс бота.
2. Скопируйте файлы из patch-архива в корень проекта с заменой.
3. Не заменяйте свой .env и не копируйте рабочий data/bot.sqlite из чужого архива.
4. Выполните:

   pnpm install --frozen-lockfile
   pnpm verify
   pnpm start

При первом импорте src/infrastructure/database/index.js сам создаст
coords_override_settings через CREATE TABLE IF NOT EXISTS. Старая база,
история, события и настройки не удаляются.

Настройка перед 22 августа
==========================

Со своего owner-профиля отправьте:

   корды сообщение

Бот ответит:

   Введите сообщение.

Следующим сообщением отправьте ТОЧНЫЙ текст, который должен видеть пользователь.
Бот подтвердит сохранение. Повторная настройка заменяет старый текст.

Управление:

   корды отключить   # в активное окно «корды» после этого молчат и не идут в GPT
   корды удалить
   корды удалить сообщение
   удалить сообщение

Окно выдачи:

   22 августа 2026, Europe/Moscow
   начало: 12:00:00 включительно
   конец:   24:00:00 (00:00 23 августа уже не входит)

В этом окне три запроса:

   корды
   корды пересоздание
   корды случайное пересоздание

получают только сохранённый текст.
