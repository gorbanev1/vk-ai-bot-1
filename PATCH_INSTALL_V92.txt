V92 — «резюмируй картинкой»: сообщения -> mini GPT -> visual prompt -> gpt-image-2.

1. Останови бота.
2. Распакуй V92 поверх проекта.
3. Не заменяй свой .env и data/.
4. Запусти:
   pnpm install --frozen-lockfile
   pnpm dev

Ожидаемая сборка:
[BOT BUILD] events-v92-image-summary-message-to-prompt-pipeline

Проверка:
Гигорейв резюмируй картинкой 1000

В логе должно быть:
[GPT IMAGE SUMMARY PIPELINE] messages=... promptModel=gpt-5.4-mini imageModel=gpt-image-2 ...
[GPT IMAGE REQUEST] model=gpt-image-2 endpoint=images/generations ...

Для текстовой подготовки можно явно задать GPT_IMAGE_PROMPT_MODEL, но это должна быть текстовая GPT-модель. По умолчанию используется default (gpt-5.4-mini в текущей конфигурации).
