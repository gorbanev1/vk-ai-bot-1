VK AI BOT — УСТАНОВКА НАКОПИТЕЛЬНОГО ПАТЧА V71
=================================================

Что исправлено
--------------
Команда «Гигорейв nvidia нарисуй ...» теперь действительно вызывает NVIDIA Visual API, получает изображение и прикрепляет его к ответу VK/Telegram. V70 только выводил сообщение о неподключённой графике.

Базовая версия
--------------
Патч накопительный. Его можно наложить поверх V66, V67, V68, V69 или V70.

1. Остановите бота
------------------
В терминале:

Ctrl+C

2. Сделайте резервную копию
---------------------------
Сохраните отдельно:

.env
data\

Патч не содержит рабочего .env и не должен заменять ваши токены и базу.

3. Установите патч
------------------
Распакуйте содержимое папки VK_AI_BOT_V71_CUMULATIVE_PATCH в:

C:\Users\Adm\WebstormProjects\vk-ai-bot

Согласитесь на замену файлов.

4. NVIDIA-переменные
--------------------
Существующего NVIDIA_API_KEY достаточно. Новые переменные необязательны, потому что в коде есть безопасные значения по умолчанию:

NVIDIA_IMAGE_BASE_URL=https://ai.api.nvidia.com/v1/genai
NVIDIA_IMAGE_MODEL=auto

NVIDIA_BASE_URL=https://integrate.api.nvidia.com/v1 остаётся отдельным endpoint для текстовых моделей.

5. Проверка
-----------

pnpm install --frozen-lockfile
pnpm run test:provider-diagnostics
pnpm run test:nvidia-image
pnpm dev

Ожидаемая строка:

[BOT BUILD] events-v71-nvidia-visual-generation

6. Готовые команды
------------------

Гигорейв nvidia графика модели
Гигорейв nvidia графика проверить
Гигорейв nvidia нарисуй ночной Воронеж в стиле киберпанка
Гигорейв nvidia нарисуй фотореалистичного рыжего кота-космонавта на Луне

Точная модель:

Гигорейв nvidia нарисуй через flux.1-schnell ночной город под дождём
Гигорейв nvidia нарисуй через flux.2-klein-4b футуристический мотоцикл
Гигорейв nvidia нарисуй через sd3 портрет алхимика
Гигорейв nvidia нарисуй через sdxl ретроафишу научной фантастики без текста

7. Что должно произойти
-----------------------
Бот отправит короткую строку «NVIDIA: генерирую изображение…», вызовет Visual API и затем пришлёт картинку с подписью вида:

🎨 NVIDIA · black-forest-labs/flux.1-schnell · 12345 мс

В режиме auto при недоступности одной функции бот попробует следующую модель. 401/403 означает проблему ключа или доступа, 429 — квоту. Account-specific 404/422 одной модели не означает, что ключ сломан.
