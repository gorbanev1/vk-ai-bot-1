# Добавление события в календарь

В карточке Telegram доступна одна кнопка «Добавить в календарь». Она открывает страницу с действиями для разных устройств.

- iPhone/iPad: подписка Apple Calendar добавляет отдельный подписной календарь, а не разовую запись в личный календарь. Обычный сайт не может сам записать событие в системный календарь iOS. Импорт одного события из ICS зависит от версии iOS и приложения: файл может показать предпросмотр, где придётся выбрать системный Calendar через «Поделиться».
- Android/Huawei: кнопка передаёт данные через Android ACTION_INSERT и просит совместимый календарь открыть форму события. Пользователь проверяет поля и нажимает «Сохранить». Это сработает, если Telegram/браузер передаст Intent и установленный календарь его обработает; ICS остаётся запасным вариантом.
- Google Calendar: открывается заполненная форма события, которую нужно подтвердить.
- Яндекс Календарь, Mac и Windows: универсальной системной ссылки, которая гарантированно запишет событие в выбранный календарь, нет. Используй импорт ICS в нужном приложении. Справка Яндекса: https://yandex.ru/support/yandex-360/customers/calendar/web/ru/data-exchange/import.

Подписка создаёт отдельный календарь с названием события и просит клиент обновлять feed каждые 15 минут. Feed содержит одно напоминание за день, но клиент может игнорировать VALARM в подписках. Если событие не видно, открой приложение «Календарь» → «Календари» и проверь, что подписка включена.

## Файл сайта

Загрузи hosting/calendar.php в корневую папку gigorave.tw1.ru, заменив прежний calendar.php. .htaccess менять не нужно, если секрет не менялся. Endpoint: https://gigorave.tw1.ru/calendar.php.

Без параметров endpoint вернёт 400 Invalid calendar request; это ожидаемо. Проверяй страницу на свежей карточке после перезапуска бота. Изменение локального PHP-файла само по себе не обновляет сайт.

## Диагностика хостинга

Для проверки телефона открой https://gigorave.tw1.ru/calendar.php?health=1&probe=iphone-test-01. Если PHP получил запрос, он вернёт JSON ok: true, значение probe и заголовок X-Request-ID.

В панели Timeweb открой логи сайта gigorave, PHP/error log, найди [gigorave-calendar] с probe=iphone-test-01. Чтобы проверить запрос подписки, добавь &probe=iphone-sub-01 в конец URL webcal:// и нажми его на телефоне. Строка received с probe и User-Agent означает, что запрос дошёл до PHP; finished со статусом 200 означает, что PHP сформировал feed. Если телефон висит и строки с probe нет, запрос не дошёл до скрипта. Если received есть без finished, проблема возникла в PHP.

Ищи по точной метке probe и времени с часовым поясом. Не отправляй в поддержку полный URL подписки: параметры URL содержат данные события. Если HTTPS зависает до PHP и записи нет, передай хостингу время, домен и факт зависания запроса. Если запись есть, приложи request_id и статус.
