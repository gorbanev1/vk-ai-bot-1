# Gigorave V188.79 — без лишних reload + Telegram menu UX

## Исправлено

- VK-источник больше не перезагружается только из-за того, что точный DOM-селектор вернул 0 постов при уже нормально загруженной стене.
- Перед реальным автоматическим reload страница ждёт минимум 10 секунд и проходит повторную page-health проверку. Если за это время стена стала здоровой/контент появился, reload отменяется.
- `parser-zero-posts` на странице со статусом `wall-content-present` теперь считается selector/parser miss и передаётся structural/heuristic контурам без навигации страницы.
- Реальный reload остаётся только для подтверждённого empty/error состояния после повторной проверки. CAPTCHA/login по-прежнему не входят в reload-loop.

## Второстепенные / быдлячьи источники

- Удалён ошибочный Telegram-контакт `t.me/LITERA_VRN_RESTOBAR` (это карточка `SEND MESSAGE`, не канал с лентой).
- `vk.com/literabar` оставлен как источник Литеры.
- Старое сохранённое вручную значение `tg:litera_vrn_restobar` также фильтруется из secondary registry, чтобы не вернуться после обновления.
- В secondary seed теперь 25 валидных source entries.

## Telegram UI

- Reply keyboard больше не помечается `is_persistent`, поэтому её можно свернуть штатной кнопкой Telegram.
- В каждую reply-клавиатуру добавлена явная кнопка `⌨️ Скрыть клавиатуру`; она отправляет `remove_keyboard: true` и не ломает текущий pending mode/menu path.
- Кнопка раздела теперь: `🍺 Второстепенные / быдлячьи тусы 🥴` — разные характерные emoji слева и справа.
- `⬅️ Назад` добавлена в меню `Тусы` и сохраняется во всех подветках.
- Навигация стала иерархической: secondary -> Тусы -> Главное меню; document action -> Документы -> Главное меню; action, открытый из Тусов, возвращается в Тусы.
