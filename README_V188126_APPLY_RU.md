# GIGORAVE V188.126 — обычный Telegram TXT → GPT-5.6 Terra (high) → итоговый TXT

Обновление поверх существующей рабочей установки V188.125. ZIP — исходный накладываемый патч, а не самостоятельная установка: не удаляйте файлы, отсутствующие в ZIP. Остановите бота; сохраните .env, data, журналы заданий, SQLite и outbox; распакуйте файлы архива поверх проекта; запустите бот и проверьте `[BOT BUILD] V188.126`.

**Что исправлено.** В ЛС владельца ОДНО обычное текстовое вложение `.txt`, `.md`, `.markdown`, `.log`, `.json`, `.csv`, `.yaml` или `.yml` всегда попадает в специальный TXT-анализ ДО generic GPT file-input, даже если в подписи не названа модель, подпись пустая или ошибочно говорится «архив». Исходный файл скачивается из Telegram, декодируется как UTF-8 и передаётся текстом в запрос модели, `inputFiles=[]`. Результат доставляется документом `GIGORAVE_TEXT_ANALYSIS.txt`, а не обычным длинным сообщением или Word.

Модель по умолчанию **gpt-5.6-terra**, `reasoningEffort=high`, `verbosity=high`. Явное `gpt-5.5` в подписи оставляет существующую возможность выбрать 5.5. Специальная команда `Гигорейв astra max` для текста по-прежнему НЕ вызывает Astra — это старое имя маршрута. Встроенный fallback, который незаметно убирает высокое reasoning после 400/422, отключён. Если настроенная через `GPT_MODEL_PRO2` модель не Terra, специальный маршрут явно откажет, а не направит текст в `gpt-5.4-mini`.

ZIP, DOCX, изображения, вложения в группах и запросы не от владельца не перехватываются этим маршрутом; ZIP-аудит и обработка VK не менялись. При пустой подписи для вложения используется штатная инструкция проанализировать сам текстовый файл. Если роутер явно отвергает ПОЛНЫЙ текст из-за размера или контекстного лимита, запускается уже существующий последовательный анализ частями. При неопределённой ошибке потока повторные платные POST по умолчанию выключены. Старый Astra responseId со статусом GET 404 этим патчем не восстанавливается и не запускается заново.

**Проверка:** локальные тесты и синтаксис; не проводились реальная генерация Terra на 2 МБ, проверка токенов у роутера и отправка Telegram. Если провайдер не принимает большой текст, возможен контекстный отказ или долгая работа. Результат и тариф модели не гарантированы исходниками.

Проверка после установки: отправьте единственный TXT с подписью «Проведи ревью этого текстового файла и верни один TXT». В консоли ожидаются `[TEXT ATTACHMENT ROUTE] ... genericFileInput=bypassed`, `[TEXT ATTACHMENT MODEL] model=gpt-5.6-terra reasoning=high files=0`; НЕ должен появляться `[GPT TELEGRAM FILE INPUT]` для этого задания. Проверяйте `model=gpt-5.6-terra reasoning_requested=high` в `[AI RUNTIME TRANSPORT]` и получение итогового `GIGORAVE_TEXT_ANALYSIS.txt`.
