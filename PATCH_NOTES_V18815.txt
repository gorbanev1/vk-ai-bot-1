Gigorave V188.15

1. Startup catch-up for missed auto-summary slots
- First scheduler tick after boot explicitly runs in startupCatchUp mode.
- Missed intermediate slots are collapsed to the latest due slot to avoid chat spam.
- Cumulative summary includes messages through startup time.
- Catch-up never crosses the 06:00 Europe/Moscow bot-day boundary.
- VK history retrieval may scan up to 100,000 messages and stops as soon as the requested start timestamp is reached.

2. AI token usage ledger
- Logs operation/provider/key-name/model/transport/duration.
- Stores exact input/output/total/cached/reasoning usage when the provider returns it.
- Otherwise records a clearly marked text-token estimate; exact counters remain zero.
- Auto-summary stages are separately labeled leaf/merge.
- Daily JSONL: data/ai-token-usage/YYYY-MM-DD.jsonl
- Override directory: AI_TOKEN_USAGE_LOG_DIR
- Prompt contents and API key secrets are not written.

Optimization report:
  npm run tokens:report
  npm run tokens:report -- /path/to/one-day.jsonl
