Gigorave V174 — live-save hardening + multi-strategy recovery + situational active chat

HISTORY / DURABILITY
- Live VK messages are persisted before command/AI/recovery side effects.
- Added append-only live-message journaling so a transient SQLite failure cannot silently lose a newly received message.
- Startup recovery mines readable local SQLite snapshots before trying network strategies.
- Recovery cycles through available VK API strategies and configured VK actors; browser recovery remains a final fallback path.
- Network recovery is isolated from live-save so a failed recovery method cannot stop ordinary message storage.

ACTIVE COMMUNICATION
- Autonomous replies use a larger recent-chat window (up to roughly 50 messages) instead of reacting to a single isolated line.
- The prompt asks the model to infer the current tone and choose an appropriate conversational move: continue the topic, ask a relevant question, support, tease, joke harshly when context supports it, disagree, or react briefly.
- The bot is prompted to sound like a real participant in the existing conversation rather than an assistant commenting from outside it.
