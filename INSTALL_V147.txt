Gigorave V147 — установка
========================

1. Остановить бот.
2. Сделать копию своей рабочей папки, особенно `.env` и `data/bot.sqlite`.
3. Full: распаковать V147 поверх проекта, НЕ заменяя свой `.env` и `data/bot.sqlite`.
   Patch: распаковать V147 patch поверх V146.
4. `npm install` только если зависимости ещё не установлены.
5. Запустить бот обычной командой.

При первом запуске V147 одноразовая миграция сама ремонтирует существующий SQLite:
- очищает у multi-event/digest child rows одинаковые унаследованные картинки;
- очищает старые generated event-card paths;
- инвалидирует старый dedupe registry и заставляет scraper state пройти новой версией;
- сырые source-post evidence не удаляет.

После запуска рекомендуется один раз выполнить:
`Гигорейв парсер все`

Затем проверить:
`Гигорейв тусы сентябрь`

Для digest-события с плохой старой картинкой V147 не показывает её. Он ищет отдельный VK-анонс через Chromium и при успехе записывает точный source_url + poster обратно в SQLite. Если отдельный poster не найден, карточка идёт текстом, а не с чужой/самодельной картинкой.
