Gigorave V188.5

1. Telegram menu "Тусы"
- Added public "➕ Добавить тусу".
- Owner also gets "🛠 Добавить тусу (владелец)" and "Добавить источник".
- Party menu navigation is a single "🏠 Главное меню" button.

2. VK direct-post recovery
- New VK UI can render an opened wall post in a modal/dialog without legacy .Post/.wall_post_cont/role=article selectors.
- For exact wall URLs the browser now locates the visible wall permalink/container and rescues that exact post as the primary event source.
- Modal/dialog fallback is used when VK no longer keeps a wall permalink inside the rendered post DOM.

3. AI provider gating fix for event proposals
- Event proposal extraction is no longer gated on the legacy primary OPENAI_COMPAT_API_KEY variable.
- It can use any configured runtime model credential (OPENAI_COMPAT_API_KEY[_N] or XAI_API_KEY[_N]) through the existing provider/key failover layer.
- Vision extraction likewise no longer silently disables itself just because the legacy primary key is absent.

This directly fixes the case where the VK post is visibly open in the scraper browser but the bot still says it could not recognize a concrete event.
