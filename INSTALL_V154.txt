GIGORAVE V154 — INSTALL

1. Остановить текущий процесс бота.
2. Сделать резервную копию data/.
3. Распаковать V154 поверх V153 либо использовать patch V153 -> V154.
4. Не удалять data/: SQLite и registry источников сохраняются.
5. Выполнить npm install / npm ci вашим обычным способом.
6. Запустить на Node >=24.

После первого запуска старый verified snapshot V153 будет проигнорирован из-за новой версии алгоритма дедупа.

Рекомендуемая проверка:
- `Гигорейв тусы проверить`
- затем `тусы эти выходные`

Кейс `ГРАНИ` + `ГРАНИ гиг` в Diesel Bar должен показываться одной карточкой.
`Diesel Bar` и `Diesel Hall` должны оставаться разными площадками.
