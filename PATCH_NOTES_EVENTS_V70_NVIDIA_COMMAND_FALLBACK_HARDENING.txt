V70 — NVIDIA Command Fallback Hardening

Новая сборка: events-v70-nvidia-command-fallback-hardening.

Исправленная регрессия

Команда вида:
  Гигорейв nvidia нарисуй <описание>

раньше попадала в общий fallback и выводила длинную NVIDIA-справку. Это было неверно: пользователь просил действие, а получал документацию.

Изменения

1. Явно распознаются графические формулировки:
   nvidia нарисуй ...
   nvidia картинка ...
   nvidia изображение ...
   nvidia сгенерируй картинку ...

2. Поскольку NVIDIA image endpoint в текущей сборке ещё не подключён, бот отвечает коротко:
   - графика NVIDIA не подключена;
   - запрос не отправлен;
   - для текущей генерации можно использовать обычную команду «Гигорейв нарисуй ...» через gpt-image-2.

3. Любая неизвестная короткая NVIDIA-команда теперь получает короткую ошибку. Она не падает в длинный help и не уходит в обычный GPT-router.

4. Добавлена удобная текстовая форма без ручного выбора модели:
   Гигорейв nvidia текст <вопрос>

Она эквивалентна NVIDIA-запросу с автоматическим поиском реально доступной chat-модели.

5. Полная справка остаётся доступна только по явным формам:
   Гигорейв nvidia
   Гигорейв nvidia помощь
   Гигорейв nvidia примеры
