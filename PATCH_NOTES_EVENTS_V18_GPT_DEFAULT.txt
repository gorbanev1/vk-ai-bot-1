EVENTS V18 — GPT ПО УМОЛЧАНИЮ И РЕЗЮМЕ-КАРТИНКА

1. Все обычные AI-вызовы теперь используют GPT:
   - обычные вопросы;
   - текстовое резюмирование;
   - определение периода афиши;
   - FAQ-классификация в личных сообщениях;
   - извлечение места для прашны;
   - анализ событий при ручной прокрутке VK-бесед;
   - ежедневное обновление досье и стиля ответов.

2. GigaChat вызывается только при явном префиксе:
   - Гигорейв гигачат <запрос>
   - Гигорейв гигачат резюмируй 100 сообщений
   - Гигорейв гигачат нарисуй <описание>

   GIGACHAT_CREDENTIALS больше не обязательны для запуска бота.

3. Команда «резюмируй картинкой» работает в два этапа:
   - базовая текстовая GPT создаёт такое же фактическое резюме, как команда
     «резюмируй»;
   - GPT image получает инструкцию:
     «Нарисуй изображение по мотивам общения в чате»
     и готовое текстовое резюме.

   Сырые 100/500 сообщений напрямую в image-модель больше не передаются.

4. Исправлена отправка GPT-картинки во VK:
   - buffer проверяется как настоящее PNG/JPEG/WEBP/GIF;
   - изображение сначала сохраняется во временный файл;
   - результат vk.upload.messagePhoto проверяется;
   - в messages.send передаётся нормализованная строка photo<owner>_<id>;
   - при ошибке готовый файл остаётся в data/generated-images для диагностики.

5. Логи ручного парсера бесед переименованы с GIGACHAT на GPT.

УСТАНОВКА
Остановить бота, распаковать архив поверх проекта с заменой файлов и полностью
перезапустить процесс. Существующие .env, data и авторизованный профиль браузера
не удалять.
