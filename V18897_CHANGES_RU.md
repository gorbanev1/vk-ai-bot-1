# Gigorave V188.97 — удаление/исправление карточек владельцем

## Что исправлено

1. Команда `тусы удалить <название или часть>` больше не ищет только в уже схлопнутой публичной выдаче. Поиск идёт по текущим approved/pending строкам SQLite (`telegram_events`, `vk_events`, `vk_chat_events`, `manual_events`). Это устраняет ситуацию, когда карточка видна в афише, но команда удаления пишет «не нашёл».
2. Поиск owner-модерации стал recall-heavy: точное название, подстрока, содержательные слова, `participants`, частичное токенное совпадение и небольшие опечатки. Автоматического удаления по слабому fuzzy нет: сомнительные совпадения показываются владельцу под номерами.
3. Если найдено несколько карточек, поддерживаются `удалить 1`, `удалить 2`, `удалить 1 2`, `удалить 123`. Для permanent-delete работает тот же выбор, но выбранные строки получают durable permanent fingerprints.
4. В Telegram для найденных карточек появляются кнопки `Удалить 1`, `Удалить 2`, ... и общая кнопка удаления всех показанных карточек. После удаления возвращается меню `Тусы`; pending selection удаляется до выполнения операции, поэтому последующие команды не блокируются.
5. Добавлена команда `тусы исправить <название или часть>`. Если найдено несколько карточек — выбрать `исправить 1`. Затем владелец присылает новый текст анонса, из которого заново извлекаются смысловые поля карточки.
6. Добавлен двухшаговый вариант `тусы исправить`: бот сначала просит фрагмент названия/имя участника, затем при необходимости предлагает номера, после чего ждёт новый текст.
7. Текстовая коррекция не заменяет `image_paths_json`, `poster_vision_facts_json`, poster binding/status/reason/source lineage. То есть подтверждённая афиша не теряется из-за исправления текста.
8. Старый single-result `getCombinedUpcomingEvents(500)` удалён из owner delete/edit поиска; используется сырой DB-контур. Старый legacy title-only blacklist не возвращён в production-фильтрацию.

## Команды

- `тусы удалить Цупникова`
- `тусы удалить насовсем Цупникова`
- после списка: `удалить 1`, `удалить 1 2`, `удалить 123`
- `тусы исправить Цупникова` → при необходимости `исправить 1` → новый текст анонса
- `тусы исправить` → фрагмент названия → выбор → новый текст
