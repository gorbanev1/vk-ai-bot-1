Установка накопительного патча V70

1. Остановите бота: Ctrl+C.
2. Сделайте резервную копию проекта.
3. Распакуйте содержимое VK_AI_BOT_V70_CUMULATIVE_PATCH в корень:
   C:\Users\Adm\WebstormProjects\vk-ai-bot
4. Согласитесь на замену файлов.
5. Не удаляйте и не заменяйте .env и data\.
6. Выполните:
   pnpm install --frozen-lockfile
   pnpm run test:provider-diagnostics
   pnpm dev
7. В логе ожидается:
   [BOT BUILD] events-v70-nvidia-command-fallback-hardening

Проверка после установки

1. Графическая NVIDIA-команда, которая пока не реализована:
   Гигорейв nvidia нарисуй ночной Воронеж в стиле киберпанка

   Ожидается короткий ответ о том, что NVIDIA-графика не подключена.
   Длинная справка выводиться не должна. Запрос не должен уходить в GPT.

2. Неизвестная команда:
   Гигорейв nvidia сделай что-нибудь странное

   Ожидается короткая ошибка и ссылка на «Гигорейв nvidia помощь».

3. Короткий текстовый запрос без указания модели:
   Гигорейв nvidia текст Объясни RAG одним абзацем

   Бот сам подберёт рабочую NVIDIA chat-модель.

4. Полная справка по-прежнему доступна явно:
   Гигорейв nvidia помощь
