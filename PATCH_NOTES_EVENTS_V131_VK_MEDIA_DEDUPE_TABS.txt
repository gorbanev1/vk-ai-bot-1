Gigorave V131 — VK media + schedule parsing/dedupe + tab reuse

Исправлено по реальным кейсам Liverpool/VK:
- Расписание вида «27 августа, 20.00 - Кошка Сашка» теперь разбирается как отдельные события, а не как одна карточка из первого пункта.
- Строка «27 августа, 20.00» больше не становится названием; время 20.00 извлекается как 20:00.
- Дубликат между отдельным коротким постом и тем же пунктом закреплённого расписания склеивается только при безопасном наборе признаков: тот же паблик + дата + близкое время + та же площадка + ровно одна слабая/служебная карточка.
- Два разных нормально названных события в том же паблике/месте/времени этим правилом НЕ склеиваются.

VK-фото:
- Постеры добираются пакетным VK API wall.getById для максимум 20 уже выбранных постов.
- DOM fallback теперь понимает currentSrc/src/srcset/data-srcset/data-original/data-lazy-src/picture source и computed background-image.
- Lazy media прогревается для всех 20 постов, а не только для 10.
- Если раньше вместо реального постера сохранилась сгенерированная fallback-картинка или файл пропал, тот же пост разрешено повторно обработать и восстановить реальное фото.

Вкладки:
- Для оставляемых владельцу VK/Telegram/manual-review вкладок введено переиспользование по стабильному ключу.
- Повторные команды не должны плодить одинаковые вкладки.
- Ручная прокрутка после автоматического прохода не запускает фоновый парсинг; автоматический лимит остаётся 20.
