GIGORAVE V130 — УСТАНОВКА

1. Остановите запущенный бот.
2. Сохраните свои .env и папку data (особенно data/bot.sqlite) отдельно.
3. Полный архив: распакуйте V130 в отдельную папку и перенесите туда свой .env и data.
   Патч: распакуйте Gigorave_V130_patch_from_V129.zip поверх чистого V129 с заменой файлов.
4. Зависимости не менялись. Если node_modules отсутствует: pnpm install (или npm install, если проект так уже запускается у вас).
5. Запустите бот обычной командой проекта.
6. Проверка версии: package.json -> version = 0.130.0.

ВАЖНО V130:
- автоматическая обработка публичной страницы/сообщества/канала ЖЁСТКО ограничена 20 свежими постами;
- более глубокая история автоматически не проматывается и не разбирается;
- при ручном открытии источника вкладка браузера остаётся открытой для вашей ручной прокрутки;
- прямые ссылки на посты обрабатываются отдельно и не требуют прохода по старой ленте.

Перед заменой файлов всегда храните резервную копию .env и data.
