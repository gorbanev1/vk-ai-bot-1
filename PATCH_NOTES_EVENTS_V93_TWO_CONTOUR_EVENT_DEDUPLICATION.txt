V93 — TWO-CONTOUR EVENT DEDUPLICATION

Проблема:
Одно событие из Telegram/VK могло иметь совершенно разные заголовки и не считаться дублем.
Пример:
- Telegram: «Вечеринка с грибным эмбиентом»
- VK: «BEERBIENT»
При этом совпадают дата, площадка, время/двери и полный состав участников.

Решение:
1. Первый контур полностью без ИИ.
   - hard-block по дате;
   - сравнение нескольких времён (двери/начало считаются совместимыми до 90 минут);
   - нормализация площадки с удалением общих слов bar/club/hall/Воронеж;
   - overlap/Jaccard площадки;
   - fuzzy + token overlap названия;
   - fuzzy matching списка участников;
   - взвешенный score + сильные правила по нескольким независимым признакам;
   - явные разные даты не объединяются;
   - защита от транзитивной ложной склейки кластеров при конфликтующем времени.

2. Второй контур gpt-5.4-mini только для ambiguous-пар.
   Модель получает две структурированные карточки + score первого контура и отвечает:
   same / different / uncertain, confidence, reason.
   При низкой confidence события остаются раздельными.

3. Merge одного события:
   - один канонический title + alternativeTitles;
   - объединённый список участников без повторов;
   - более полный venue/address;
   - более информативный timeLabel (например «двери 18:00, начало 19:00»);
   - объединение разных предложений из описаний с fuzzy-дедупом предложений;
   - цена и билетные поля не теряются;
   - imagePaths/imageUrls объединяются;
   - mergedSources сохраняет Telegram и VK одновременно.

4. Алгоритм применяется после AI-нормализации перед обычной и compact-афишей.
Поэтому пользователь видит одну карточку события, а блок «Источники» может содержать оба источника.

Пример BEERBIENT в regression test объединяется автоматически первым контуром без вызова ИИ.
