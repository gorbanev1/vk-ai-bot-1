V83 — исправление фактической причины "ключи проверить все" видит только 2 ключа.

Проблема V82:
- autoimport был привязан к npm/pnpm predev/prestart;
- при прямом node src/index.js этот hook не выполнялся;
- уже работающий процесс не видел новые переменные, дописанные в .env;
- keys_audit_all проверял только process.env, поэтому мог видеть лишь OPENAI_COMPAT_API_KEY + NVIDIA_API_KEY.

Исправление V83:
1. src/index.js до dotenv запускает bot-native importer.
2. parsed_secrets.txt ищется в корне проекта рядом с src/package.json/.env.
3. importer пишет поддерживаемые AI secrets в numbered slots .env.
4. importer одновременно синхронизирует ВСЕ supported numbered slots из .env в process.env.
5. "ключи проверить все" сам повторно запускает importer непосредственно перед collectConfiguredAiCredentials().
6. Основной OPENAI_API_KEY не создаётся и не заменяется из TruffleHog-файла; импортированные OpenAI идут с OPENAI_API_KEY_2 и далее.
7. Non-AI secrets не импортируются.
8. Секреты в логах только masked.
