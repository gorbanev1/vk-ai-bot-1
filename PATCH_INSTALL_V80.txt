V80 — AI key live audit + provider pools + NVIDIA visual matrix + GPT reasoning controls

1) Останови бота (Ctrl+C).
2) Распакуй VK_AI_BOT_V80_CUMULATIVE_PATCH.zip поверх проекта vk-ai-bot.
3) Не удаляй и не заменяй существующие .env и data/.
4) Установи/проверь зависимости:
   pnpm install --frozen-lockfile

5) Если AI-ключи лежат в локальном TruffleHog JSONL/TXT, сначала dry-run:
   pnpm run import:ai-secrets -- "C:\\path\\to\\trufflehog-log.txt"

   Затем, если список количества ключей выглядит правильно:
   pnpm run import:ai-secrets -- "C:\\path\\to\\trufflehog-log.txt" --apply

   Скрипт:
   - делает backup .env;
   - импортирует только OpenAI / Anthropic / Gemini / Groq / HuggingFace / NVIDIA;
   - дедуплицирует секреты;
   - не печатает полный ключ;
   - НЕ импортирует Stripe/AWS/GitHub/Cloudflare/SendGrid/JWT.

6) Проверки:
   pnpm run test:reasoning-routing
   pnpm run test:key-audit
   pnpm run test:external-providers
   pnpm run test:nvidia-visual-audit
   pnpm run test:nvidia-image
   pnpm run test:provider-diagnostics

7) Запусти:
   pnpm dev

Ожидаемая сборка:
[BOT BUILD] events-v80-ai-key-live-audit-nvidia-visual-matrix-reasoning

OWNER-ONLY LIVE COMMANDS

Гигорейв ключи проверить все
  Небиллинговая live-проверка всех настроенных AI credentials.
  В чат приходит короткая сводка.
  Полный отчёт: ./AI_KEYS_LIVE_CHECK_REPORT.txt
  JSON:          ./AI_KEYS_LIVE_CHECK_REPORT.json

Гигорейв nvidia графика тест все
  Последовательно генерирует одинаковый сюжет всеми hosted image-generation моделями.
  Если к сообщению приложена картинка, после генерации запускает и edit matrix.
  Отчёт: ./NVIDIA_VISUAL_LIVE_TEST_REPORT.txt

Гигорейв nvidia графика генерация тест все
  Только generation matrix.

Гигорейв nvidia графика редактирование тест все
  Требует приложенную картинку/reply на картинку. Проверяет editing endpoints.

GPT REASONING

По умолчанию:
- gpt-5.4-mini / gpt-5.4 / gpt-5.5: medium
- gpt-5.6-luna / terra / sol: high

Явные modifiers:
low / medium / high / xhigh / x-high / max

Примеры:
Гигорейв pro3 xhigh проведи глубокий анализ ...
Гигорейв sol max ...   (если alias sol поддерживается текущим gptModeRouting)
Гигорейв интеллект high ...

Если конкретный OpenAI-compatible endpoint не принимает reasoning_effort, существующий compatibility fallback повторяет запрос без этого параметра.
