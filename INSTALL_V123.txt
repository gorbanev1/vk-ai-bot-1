GIGORAVE V123 — установка / обновление с V121

1. Остановить bot process.
2. Сделать резервную копию data/bot.sqlite и .env.
3. Наложить patch V121→V123 с заменой файлов ИЛИ использовать full V123 как чистый source tree и вернуть свои .env/data отдельно.
4. pnpm install (если зависимости ещё не установлены).
5. pnpm dev

Telegram Pinball:
- локально сервер по умолчанию: http://127.0.0.1:8787/pinball/
- для кнопки Telegram нужен публичный HTTPS reverse proxy;
- добавить в .env: TELEGRAM_PINBALL_WEBAPP_URL=https://YOUR_DOMAIN/pinball/
- при необходимости PINBALL_HTTP_HOST / PINBALL_HTTP_PORT / PINBALL_INITDATA_MAX_AGE_SEC.

AI audit:
- команда: Гигорейв тест всех моделей
- GigaChat и OPENAI_COMPAT_API_KEY владельца не тестируются;
- доказанно invalid чужие ключи удаляются из .env только после завершённого аудита;
- перед изменением создаётся .env.before-ai-key-cleanup-<timestamp>.bak.

Не удалять data/bot.sqlite для обновления.
