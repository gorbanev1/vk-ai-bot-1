# V188.95 — Swiss Ephemeris local-first

Исправлен сценарий, при котором прашна падала сообщением `EPHEMERIS_PATH ... не настроен` и до модели ничего полезного не доходило.

## Новый контракт

1. Любой натал/прашна, в том числе обычный `Гигорейв прашна ...` без указания модели, **сначала** пытается рассчитаться локально.
2. Перед расчётом бот ищет полный набор `sepl_18.se1`, `semo_18.se1`, `seas_18.se1` в `EPHEMERIS_PATH` и стандартных каталогах проекта.
3. Если файлов нет, один раз выполняется bounded auto-bootstrap в `data/swisseph` с официального каталога Swiss Ephemeris; повторные сетевые ошибки имеют cooldown 15 минут.
4. После успешного bootstrap выставляется `EPHEMERIS_PATH`, затем запускается существующий `calculateJyotishPrashna()`.
5. Если локальный расчёт всё равно упал, запрос **не обрывается**: модели передаётся `FALLBACK_SWISS_EPHEMERIS_REQUIRED` с точным временем, местом и координатами.
6. Fallback-промпт жёстко требует реального запуска Swiss Ephemeris (`sweph@2.10.3-7`); при отсутствии библиотеки — установить через npm/pnpm. Расчёт по памяти модели запрещён.
7. Если у модели нет реальной среды выполнения кода/установки библиотеки, она обязана сообщить о технической невозможности, а не выдумывать карту.

## Ручная проверка окружения

```bash
pnpm astrology:setup
```

Для полного отключения автоматической загрузки данных:

```env
ASTROLOGY_AUTO_SETUP_SWISSEPH=0
```

Тогда бот использует только уже настроенный `EPHEMERIS_PATH`/локальные файлы и при ошибке переходит к guarded model fallback.
