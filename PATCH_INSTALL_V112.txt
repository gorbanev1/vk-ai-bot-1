V112 — установка статистики запросивших координаты

1. Остановите бота.
2. Скопируйте файлы патча поверх V111 с сохранением структуры каталогов.
3. НЕ удаляйте data/bot.sqlite. При первом запуске V112 сам мягко добавит колонку external_username в coords_request_recipients.
4. Запустите бота.
5. Проверка владельцем:
   - «сколько запросило корды» -> только число уникальных пользователей;
   - «корды юзернеймы» -> Telegram-список и VK-список.

Повторные запросы одного пользователя не увеличивают уникальное количество. Один и тот же VK ID в основном сообществе и во встрече считается одним человеком.
