Gigorave V188.2 — installation

PATCH installation (recommended if V188.1 is already installed):
1. Stop pnpm dev / the bot process.
2. Extract Gigorave_V1882_patch.zip into the project root, replacing files.
3. Do NOT delete or replace data/, .env, bot.sqlite, bot.sqlite-wal or bot.sqlite-shm.
4. Run pnpm dev.
5. Verify startup lines:
   [BOT BUILD] events-v1882-unlimited-mini-full-dossier
   [BOT PATCH] events-v1882-unlimited-mini-full-dossier

Quick checks:
- ordinary `Гигорейв <вопрос>` should not display GPT-mini quota/model banners;
- `Гигорейв gpt54 <вопрос>` should still use/show the non-mini model quota;
- `Гигорейв полное досье <имя>` should produce the expanded dossier; a repeated unchanged request should log cached=yes / gptCalls=0 for the full render.
