1. COMMON MODEL FAILOVER
- Normal text GPT requests, vision, image generation, GigaChat pool, explicit external-provider chat, STT voice transcription and NVIDIA Visual image generation now use credential failover.
- A technical failure is retried up to 3 logical times on the same key.
- After the third technical failure that key is quarantined and the request moves to the next configured key/provider.
- If every configured runtime key is temporarily unavailable, the request waits and cycles again. Default AI_FAILOVER_MAX_ROUNDS=0 means no round limit.
- Default key quarantine: 300 seconds. The request can recover sooner through another configured key/provider.
- Invalid requests/configuration and policy/content refusals are NOT retried forever. This prevents an endless loop on a request that no key can legitimately satisfy.
- Key diagnostics/audit commands intentionally remain direct: their job is to tell you which concrete key/model is broken, so silently failing over would falsify the diagnostic.

Useful env controls:
AI_KEY_FAILURES_BEFORE_ROTATE=3
AI_KEY_QUARANTINE_SECONDS=300
AI_KEY_RETRY_BASE_MS=1500
AI_KEY_RETRY_MAX_MS=15000
AI_ALL_KEYS_RETRY_MS=15000
AI_FAILOVER_MAX_ROUNDS=0

Multiple runtime compatible keys:
OPENAI_COMPAT_API_KEY=...
OPENAI_COMPAT_API_KEY_1=...
OPENAI_COMPAT_API_KEY_2=...

NVIDIA Visual also accepts:
NVIDIA_API_KEY=...
NVIDIA_API_KEY_1=...
NVIDIA_API_KEY_2=...

STT now uses all configured OpenAI/Groq/OpenAI-compatible audio-capable keys instead of only the first matching key.

2. xAI / GROK
- Added xAI as an OpenAI-compatible runtime provider.
- Official xAI base URL default: https://api.x.ai/v1
- Text/vision default: grok-4.6
- Image default: grok-imagine-image-2.0
- xAI can be fallback after the existing compatible router, or can be first.

Example fallback configuration:
XAI_API_KEY=xai-...
XAI_MODEL_DEFAULT=grok-4.6
XAI_VISION_MODEL=grok-4.6
XAI_IMAGE_MODEL=grok-imagine-image-2.0
AI_PROVIDER_ORDER=compat,xai

To prefer Grok first:
AI_PROVIDER_ORDER=xai,compat

Multiple xAI keys are supported as XAI_API_KEY, XAI_API_KEY_1 ... XAI_API_KEY_20.

3. COMMUNICATION STYLE EXAMPLES
- Added durable table communication_style_examples in personalization-v187.sqlite.
- When style processing is allowed, representative REAL user messages are stored alongside the compact style rules.
- Upgrade seeding can save recent real examples with GPT=0; it does not trigger a historical model backfill.
- Direct GPT replies receive up to 8 stored examples for the current participant.
- Active communication receives real examples for the latest author plus the existing recent-chat transcript.
- Prompt explicitly asks to imitate length, syntax, vocabulary, punctuation, slang and conversationality without copying message content.
- Default behavior is a normal short chat reply, preferably one short sentence unless the request genuinely needs explanation.
- No extra GPT call is used merely to select examples; examples are selected deterministically from real messages.
