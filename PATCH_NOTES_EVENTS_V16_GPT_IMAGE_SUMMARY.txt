EVENTS V16 — «РЕЗЮМИРУЙ КАРТИНКОЙ» ТОЛЬКО ЧЕРЕЗ GPT IMAGE

Исправлено:
- Команда «Гигорейв резюмируй картинкой ...» больше не попадает в старый GigaChat-маршрут.
- Команда без явного слова gpt автоматически преобразуется в GPT image-summary.
- Используется GPT_IMAGE_MODEL через OpenAI-compatible endpoint router.cheap.
- Команда расходует отдельную дневную квоту GPT image, а не часовую квоту GigaChat.
- Старый внутренний sendImageSummary также переведён на GPT image, чтобы случайный будущий вызов не вернул GigaChat.
- Текстовое «резюмируй ...» без слова «картинкой» по-прежнему работает через прежний текстовый маршрут.

Проверено:
- node --check src/index.js
- «резюмируй картинкой» => image-summary
- «резюмируй 500 сообщений картинкой» => image-summary
- «резюмируй изображением за 2 дня» => image-summary
- «резюмируй 100 сообщений» => summary
