V105 — dual VK communities

Добавлено одновременное подключение двух VK-сообществ через один процесс бота.

Основное:
- VK_TOKEN / VK_GROUP_ID — старое основное сообщество;
- VK_EVENT_TOKEN / VK_EVENT_GROUP_ID — второе сообщество или VK-встреча;
- оба Long Poll запускаются одновременно;
- входящие сообщения обоих сообществ проходят через общий command/event/GPT routing;
- API и upload внутри обработки сообщения используют токен того сообщества, куда пришло сообщение;
- упоминания обоих club ID распознаются;
- если заполнена только одна из пары VK_EVENT_*, запуск останавливается с понятной ошибкой.

Для vk.ru/wall-240709021_13: VK_EVENT_GROUP_ID=240709021.
