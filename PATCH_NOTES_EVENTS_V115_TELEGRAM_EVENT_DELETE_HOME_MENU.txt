V115 — Telegram event deletion keyboard: restore + home

Problem
- After owner deleted an event in Telegram, the bot replaced the normal reply keyboard with a single button:
  "Вернуть тусу <название>".
- There was no visible way to leave that temporary deletion keyboard and return to the normal start menu.

Fix
- The restore button remains available exactly as an action button.
- A second button "🏠 На главную" is shown under it.
- Pressing "🏠 На главную" clears Telegram menu state and immediately restores the normal owner main keyboard.
- Pressing "Вернуть тусу <название>" restores the blacklist rule as before; the following response uses the normal main keyboard automatically.
- The temporary keyboard is persistent until one of these actions is chosen, instead of being a one-button dead end.

Compatibility
- No database migration.
- .env and data/bot.sqlite are not touched by the patch.
- V109–V114 behavior is retained.
