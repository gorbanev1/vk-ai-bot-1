Установка накопительного патча V68
=================================

База: V66 или V67.
Патч включает изменения V67 и V68.

1. Остановите бота: Ctrl+C
2. Сделайте копию проекта.
3. Скопируйте содержимое папки VK_AI_BOT_V68_CUMULATIVE_PATCH в корень:
   C:\Users\Adm\WebstormProjects\vk-ai-bot
4. Согласитесь на замену файлов.
5. Не удаляйте и не заменяйте .env и data\
6. Выполните:

   pnpm install --frozen-lockfile
   pnpm run test:provider-diagnostics
   pnpm run test:astrology-routing
   pnpm run test:participant-question
   pnpm verify
   pnpm dev

Ожидаемая строка запуска:
[BOT BUILD] events-v68-nvidia-account-model-probe-fulltest

Первый тест NVIDIA после запуска:
Гигорейв api nvidia полный тест

Эта команда не требует model id и сама перебирает модели до первой рабочей.
