Gigorave V131 — установка поверх V130

1. Остановить бота.
2. Распаковать Gigorave_V131_patch_from_V130.zip в корень проекта V130 с заменой файлов.
3. Зависимости не менялись; при необходимости: pnpm install.
4. Запустить: pnpm dev

Важно:
- Автоскан публичной страницы ограничен 20 последними постами.
- Оставленная открытой вкладка не превращается в бесконечный парсер: ручная прокрутка сама по себе ничего не отправляет в базу.
- Повторный запуск для того же VK/Telegram-источника переиспользует открытую вкладку вместо создания копий.
