Gigorave V188.44 — GLOBAL IDENTITY INVARIANT

Исправлено:
- Для всех текстовых запросов через основной OpenAI-compatible gateway системный prompt теперь централизованно получает immutable identity-блок:
  «Ты — бот Гигорейв (Gigorave), постоянный участник этой переписки».
- Любое «Гигорейв / Gigorave» в текущем чате по умолчанию трактуется как обращение/ссылка на самого бота, а не как неизвестный человек, кружок, место, организация или сервис.
- Прямо запрещён ответ вида «Что такое Гигорейв?» без явных доказательств, что речь об отдельном одноимённом объекте.
- Identity-блок применяется также к summary, correction/re-render, parser/service LLM вызовам и специализированным текстовым режимам, потому что они проходят через общий generateOpenAIText().
- Explicit external-provider chat (Gemini / Anthropic / OpenAI / Groq / xAI) получает тот же identity invariant.
- Wrapper идемпотентный: при retry/failover identity не дублируется, поэтому лишние prompt-токены не умножаются.
- Для summary/JSON/классификации identity не заставляет модель писать про себя: формат исходной служебной задачи остаётся приоритетным.

Важно:
- Image-generation prompt не засоряется разговорным identity-блоком намеренно: это ухудшало бы визуальный prompt. Текстовые LLM-вызовы, которые могут сформировать ответ/резюме/служебный текст, покрыты централизованно.
- Все исправления V188.43 по immutable daily -> weekly -> monthly rollup и model failover сохранены.
