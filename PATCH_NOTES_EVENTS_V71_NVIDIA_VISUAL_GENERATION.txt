# V71 — NVIDIA Visual Generation

## Исправлено

V70 только перехватывал `Гигорейв nvidia нарисуй ...` и сообщал, что графика не подключена. V71 выполняет реальную генерацию через NVIDIA hosted Visual API и прикрепляет полученную картинку к ответу VK/Telegram.

## Команды

- `Гигорейв nvidia нарисуй <описание>` — автоматический перебор image endpoints.
- `Гигорейв nvidia графика проверить` — живой тест с готовым промптом.
- `Гигорейв nvidia графика модели` — список поддерживаемых Visual endpoints.
- `Гигорейв nvidia нарисуй через <model|#N> <описание>` — точный endpoint без fallback.

## Автоматический fallback

Порядок по умолчанию:

1. `black-forest-labs/flux.1-schnell`
2. `black-forest-labs/flux.2-klein-4b`
3. `stabilityai/stable-diffusion-3-medium`
4. `black-forest-labs/flux.1-dev`
5. `stabilityai/stable-diffusion-xl`

Account-specific 404/422 и временные endpoint-ошибки пропускаются. Ошибки ключа 401/403 и квоты 429 не маскируются.

## Конфигурация

```dotenv
NVIDIA_API_KEY=nvapi-...
NVIDIA_IMAGE_BASE_URL=https://ai.api.nvidia.com/v1/genai
NVIDIA_IMAGE_MODEL=auto
```

`NVIDIA_BASE_URL=https://integrate.api.nvidia.com/v1` остаётся для текстовых моделей. Visual API использует отдельный домен `ai.api.nvidia.com`.

## Проверки

- маршрутизация графических команд;
- fallback после 404;
- декодирование `artifacts[0].base64`;
- запрет сетевого вызова без ключа;
- точный selector без скрытого переключения модели;
- синтаксис изменённых JS-файлов.
