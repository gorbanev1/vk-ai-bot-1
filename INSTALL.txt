Gigorave hotfix: image command fast-path + proposal poster delivery

Changes:
1. VK group chat: explicit image commands such as "нарисуй ...", "рисуй ...", "картинка ...", "image ..." are handled even without a bot mention/reply.
2. Event proposal owner notifications now attach the prepared event poster when event.imagePaths contains a valid local image.
3. Telegram owner notification also sends the poster as a photo when available.

Install option A (replace file):
- stop the bot
- back up src/app/botApplication.js
- copy src/app/botApplication.js from this archive into the project
- run: node --check src/app/botApplication.js
- restart the bot

Install option B (unified diff):
- use Gigorave_image_command_and_proposal_photo_hotfix.patch from the separate download
- from project root: patch -p1 < Gigorave_image_command_and_proposal_photo_hotfix.patch
- run: node --check src/app/botApplication.js
- restart the bot
