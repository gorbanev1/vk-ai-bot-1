# GIGORAVE V188.127 — TXT: штатные ключи моделей, mini по умолчанию, Astra с выбором reasoning

Устанавливать поверх V188.126 без удаления отсутствующих в архиве файлов. Остановите бота и сохраните резервную копию: .env, все SQLite, data/astra-text-jobs, outbox и журналы. Распакуйте этот ZIP поверх существующего проекта и запустите бота. В логе должен быть [BOT BUILD] V188.127.

Исправлено ошибочное принудительное назначение Terra/high для текстовых вложений. Один обычный TXT/MD в ЛС владельца по-прежнему перехватывается до общего файлового маршрута и возвращается как один TXT. Без ключа модели используется штатный resolveGptModel('default'): обычно gpt-5.4-mini и обычный уровень medium. Старый PROJECT_TEXT_ATTACHMENT_MODEL в этом маршруте больше не используется: выбор модели задаётся существующими GPT_MODEL_* и ключами в подписи, а не отдельным принудительным конфигом TXT.

Примеры подписи к ОДНОМУ TXT-файлу:
- «Проведи ревью приложенного текстового файла, верни один TXT» → штатная default-модель (gpt-5.4-mini).
- «Гигорейв terra high, проведи ревью файла и верни один TXT» → режим pro2, настроенная GPT_MODEL_PRO2 (обычно gpt-5.6-terra), reasoning high.
- «Гигорейв sol xhigh, проведи ревью файла» → режим pro3, настроенная GPT_MODEL_PRO3 (обычно gpt-5.6-sol), reasoning xhigh.
- «Гигорейв astra low, проведи ревью файла» → настроенная GPT_MODEL_ASTRA (обычно gpt-6-astra), reasoning low.
- «Гигорейв astra max, проведи ревью файла» → Astra max.
- «Гигорейв astra reasoning none, проведи ревью файла» → Astra none (если роутер принимает).
- «Гигорейв astra reasoning default, проведи ревью файла» → Astra default (если роутер принимает).
Также поддерживаются ключи mini, gpt54, gpt55, luna/pro, terra/pro2, sol/pro3, astra/gpt6 и уровни low, medium, high, xhigh, max. Astra явно принимает все уровни default, none, low, medium, high, xhigh, max в селекторе; поддержка уровня конкретным сторонним роутером не гарантируется. Неподдерживаемый режим должен выдавать ошибку без тихой подмены модели/уровня и без нового POST на другую модель.

TXT создаётся после успешного получения ПОЛНОГО ответа. При ошибке с известным responseId повторный платный POST автоматически не выполняется; восстановление GET ранее сохранённого streaming ID зависит от роутера (для старого ID уже получен HTTP 404). Большие файлы сначала отправляются целиком, а делятся только после явного отказа контекстного лимита/размера. Локальные тесты и синтаксис не заменяют реальный тест Telegram/роутера. ZIP-аудит и VK-код этим исправлением не менялись.

Проверка после установки: для TXT без модели ожидайте [TEXT ATTACHMENT MODEL] mode=default model=gpt-5.4-mini reasoning=medium; при «terra high» — mode=pro2 model=gpt-5.6-terra reasoning=high; при «astra low» — mode=astra model=gpt-6-astra reasoning=low. Фактический выбранный ID может отличаться, если он намеренно настроен через штатный GPT_MODEL_*. Не должен появляться [GPT TELEGRAM FILE INPUT] для этого TXT-задания; результат приходит документом GIGORAVE_TEXT_ANALYSIS.txt.
