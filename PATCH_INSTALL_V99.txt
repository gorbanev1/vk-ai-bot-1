1. Перед установкой сохраните текущие .env и data/bot.sqlite.
2. Наложите файлы V99 поверх текущей V98.
3. Запустите бот один раз. Миграция `events-v99-party-and-coords-2026-08-22`:
   - обновит party FAQ;
   - установит `51.691730, 39.251385`;
   - включит coords override;
   - запишет marker, поэтому повторный старт уже не будет перетирать owner-настройки.
4. Проверка владельцем:
   `корды` -> `51.691730, 39.251385`
   `координаты` -> `51.691730, 39.251385`
   `ближайшая туса` -> канонический анонс.
5. Для остальных coords override доступен только 22.08.2026 12:00–24:00 Europe/Moscow.
