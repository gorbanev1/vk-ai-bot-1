ПОЛНЫЙ СПИСОК КОМАНД NVIDIA V67
================================

Все команды доступны только владельцу.
NVIDIA здесь является отдельным диагностическим провайдером и не заменяет обычные команды GPT/pro/pro2/pro3.

1. Статус настроек
------------------
Гигорейв api nvidia статус

Показывает, видит ли бот NVIDIA_API_KEY, endpoint и NVIDIA_MODEL_DEFAULT. Сам ключ не выводится.

2. Проверка ключа
-----------------
Гигорейв api nvidia проверить

Успех:
✅ NVIDIA NIM API: ключ принят.
HTTP: 200

Это подтверждает авторизацию и доступ к GET /models.

3. Полный каталог моделей
-------------------------
Гигорейв api nvidia модели

Модели выводятся так:
#17 organization/real-model-id

Номер #17 можно вставлять в test/request. Номера относятся к полному отсортированному каталогу текущего запуска.

5. Короткий тест chat/completions
---------------------------------
Автоматический выбор вероятной chat-модели:
Гигорейв api nvidia тест авто

По номеру из каталога:
Гигорейв api nvidia тест #17

По точному id:
Гигорейв api nvidia тест organization/real-model-id

По уникальной части имени:
Гигорейв api nvidia тест nemotron-70b

Если часть имени подходит нескольким моделям, бот покажет совпадения и попросит точный id или #N.

6. Готовые примеры с реальным model id
--------------------------------------
Гигорейв api nvidia примеры

Бот сначала получает актуальный каталог, выбирает реальную chat/instruct-модель и печатает готовые команды. Их можно копировать дословно.

7. Разнообразные прямые запросы
-------------------------------
Вместо MODEL ниже используйте реальный id, #N или слово авто.
Не используйте строку organization/model-name: это была только заглушка.

Связность API:
Гигорейв api nvidia запрос MODEL Ответь ровно одним словом: работает

Русский язык:
Гигорейв api nvidia запрос MODEL Объясни простыми словами, что такое квантовая запутанность

Арифметика:
Гигорейв api nvidia запрос MODEL Реши по шагам: 17 * 24 - 39

Логическая задача:
Гигорейв api nvidia запрос MODEL У Маши 5 красных и 7 синих шаров. Она достала 3 шара без возврата. Объясни, каких данных не хватает для точной вероятности получить два красных

Строгий JSON:
Гигорейв api nvidia запрос MODEL Верни только JSON с полями status, answer и confidence для вопроса: Земля вращается вокруг Солнца?

JavaScript:
Гигорейв api nvidia запрос MODEL Напиши функцию JavaScript safeDivide(a, b) с проверкой деления на ноль и двумя примерами

Поиск ошибки в коде:
Гигорейв api nvidia запрос MODEL Найди ошибку в коде: const values = [1,2,3]; console.log(values[3].toString())

Рефакторинг:
Гигорейв api nvidia запрос MODEL Перепиши в современном JavaScript и объясни изменения: function add(a,b){return a+b;}

Перевод:
Гигорейв api nvidia запрос MODEL Переведи на английский: Сегодня мы проверяем отдельный NVIDIA API

Резюме:
Гигорейв api nvidia запрос MODEL Сожми до двух предложений: Большие языковые модели предсказывают продолжение текста на основе обучающих данных

Классификация:
Гигорейв api nvidia запрос MODEL Классифицируй тон сообщения как positive, neutral или negative: Сервис работает, но отвечает медленно

Таблица:
Гигорейв api nvidia запрос MODEL Сравни в таблице REST и WebSocket по задержке, направлению обмена и типичным задачам

Следование формату:
Гигорейв api nvidia запрос MODEL Назови три планеты. Каждая строка должна иметь формат НОМЕР|НАЗВАНИЕ и больше ничего

Проверка отказа от выдумывания:
Гигорейв api nvidia запрос MODEL Не угадывай. Скажи, можно ли определить текущую температуру в Воронеже без доступа к погодным данным, и объясни почему

Творческий текст:
Гигорейв api nvidia запрос MODEL Напиши короткую киберпанк-сцену о ночном Воронеже, не больше 120 слов

Контекст и извлечение:
Гигорейв api nvidia запрос MODEL Из текста «Заказ 481 доставят 5 августа с 14:00 до 18:00» извлеки номер заказа, дату и временной интервал в JSON

8. Как трактовать ошибки
------------------------
GET /models HTTP 200:
Ключ работает и авторизация принята.

401/403 на GET /models:
Ключ неверный, отозван или не имеет доступа.

429:
Лимит или квота.

GET /models=200, POST /chat/completions=404:
Ключ работает. Выбранная модель отсутствует на chat endpoint либо не поддерживает chat/completions.

400:
Обычно модель существует, но не принимает формат запроса или параметр.

Timeout/ECONNRESET:
Сетевая проблема, не доказательство неисправного ключа.
