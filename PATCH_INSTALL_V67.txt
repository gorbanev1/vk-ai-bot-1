V67 устанавливается поверх V66 и включает предыдущую защиту NVIDIA-ключей.

Что исправлено одним патчем:
- прашна/натал больше не перехватываются анализом участника беседы;
- формулировки «локальным софтом», «локальным движком», «локальным ПО» включают максимальный локальный расчёт;
- NVIDIA model id проверяется по GET /models до POST /chat/completions;
- строки organization/model-name, model-name и <model> считаются примерами-заглушками и не отправляются в API;
- список NVIDIA-моделей получает постоянные для текущего каталога номера #N;
- команды тест/запрос принимают точный id, #N, уникальную часть имени или «авто»;
- команда «Гигорейв api nvidia примеры» выдаёт готовые тесты с реальным model id;
- при GET /models=200 и POST /chat/completions=404 бот прямо сообщает, что ключ работает, а ошибка относится к модели/endpoint;
- секреты nvapi-... и NVIDIA_API_KEY=... скрываются в приватных ошибках.

Установка:
1. Остановите бота: Ctrl+C.
2. Сделайте резервную копию проекта.
3. Распакуйте содержимое patch-архива в корень проекта с заменой файлов.
4. НЕ заменяйте и НЕ удаляйте .env и папку data.
5. Выполните:

   pnpm install --frozen-lockfile
   pnpm verify
   pnpm dev

После запуска должна появиться строка:
[BOT BUILD] events-v67-nvidia-model-selector-prashna-routing

Проверка NVIDIA:
Гигорейв api nvidia проверить
Гигорейв api nvidia модели llama
Гигорейв api nvidia тест авто
Гигорейв api nvidia примеры

Проверка прашны:
Гигорейв pro3 прашна локальным софтом: <вопрос>

В логе ожидается:
astrology=prashna localCalculation=true modelCalculation=false routeReason=explicit-local-maximum packet=maximum
и затем [PRASHNA EPHEMERIS].

Новых зависимостей и миграций SQLite нет.
