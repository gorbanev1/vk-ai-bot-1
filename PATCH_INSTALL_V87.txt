V87 — краткая афиша одним общим сообщением + V86 scraper media settle

1. Останови бота.
2. Распакуй V87 поверх текущего проекта V85/V86.
3. НЕ заменяй свой .env, data/, SQLite и scraper-browser-profile.
4. Установи зависимости при необходимости:
   pnpm install --frozen-lockfile
5. Запусти:
   pnpm dev
6. Ожидаемая строка:
   [BOT BUILD] events-v87-compact-party-list-mini-gpt

Краткая афиша:
  Гигорейв ближайшие тусы кратко
  Гигорейв тусы на этих выходных коротко
  Гигорейв тусы на месяц кратко
  Гигорейв кратко тусы в августе

Поведение compact-режима:
- все события выбранного диапазона собираются в один общий логический ответ;
- картинки НЕ загружаются и НЕ отправляются;
- gpt-5.4-mini делает только 2–3 коротких предложения описания каждого события;
- дата/время/локация/участники/цена/билетная ссылка форматируются самим ботом из уже найденных фактов;
- модель не имеет права удалять события; если она пропустила элемент, бот использует локальный краткий fallback;
- если общий текст физически превышает лимит сообщения VK/Telegram, transport может разделить его на части, но бот не возвращается к схеме «одна туса = одно сообщение».

V86 включён внутрь V87:
- deadway36, liverpool_pub_vrn, idmamaanarchy, meetbowling.club, vavilone_rb — минимум 10 последних постов;
- VK последовательно показывает первые 10 постов в viewport и ждёт lazy-media;
- Telegram прокручивает страницу, ждёт изображения/background-image и держит вкладку открытой перед фиксацией HTML.
