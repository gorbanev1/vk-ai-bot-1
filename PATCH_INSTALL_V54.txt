Установка Events V54 поверх V53

1. Остановить бота.
2. Сделать резервную копию проекта, .env, data и браузерного профиля.
3. Распаковать компактный V54-патч поверх V53 с заменой файлов.
4. При необходимости добавить в .env:

GPT_VISION_MODE=pro2
GPT_VISION_MODEL=

Пустой GPT_VISION_MODEL означает использование модели режима GPT_VISION_MODE. По умолчанию это gpt-5.6-terra. Для максимального анализа можно указать GPT_VISION_MODE=pro3 либо писать «pro3 что на картинке» в самой команде.

5. Выполнить npm install только если зависимости проекта ещё не установлены. Новых зависимостей V54 не добавляет.
6. Выполнить npm run verify.
7. Запустить npm start.

Миграция SQLite не требуется. .env, data и авторизованные браузерные профили архивом не заменяются.
