V88 — восстановление Playwright после закрытого browser/context + повтор ошибок + закреплённые вкладки

1. Остановить бота.
2. Распаковать V88 поверх проекта.
3. Не удалять .env, data/, SQLite и data/scraper-browser-profile.
4. pnpm install --frozen-lockfile
5. pnpm dev

Ожидаемая сборка:
[BOT BUILD] events-v88-scraper-browser-recovery-pinned-errors

Проверка:
Гигорейв парсер все

Если источник упал из-за закрытой page/context/browser:
- бот автоматически повторит его один раз;
- перед повтором мёртвый cached-context будет отброшен;
- живой context бот специально не закрывает;
- если первая попытка падала, после повторной обработки открывается отдельная контрольная вкладка;
- контрольная вкладка НЕ закрывается кодом — только пользователем/самим Chrome;
- если обе попытки неуспешны, бот всё равно попытается открыть источник отдельной контрольной вкладкой и продолжит следующие источники.
