УСТАНОВКА PATCH V65 ПОВЕРХ V64

1. Остановите бот.
2. Скопируйте содержимое patch-архива V65 в корень проекта с заменой файлов.
3. Не заменяйте собственные .env, data/, SQLite и браузерные профили.
4. Выполните:

   pnpm install --frozen-lockfile
   pnpm verify
   pnpm dev

Новых npm-зависимостей, переменных .env и миграций SQLite нет.

После запуска Telegram получает до трёх попыток подключения. При сетевом сбое бот продолжает VK и автоматически повторяет подключение Telegram каждые пять минут.

Диагностическая owner-команда из VK:

   Гигорейв телеграм проверить

Она проверяет api.telegram.org, t.me, токен, webhook и повторное подключение, не публикуя токен.
