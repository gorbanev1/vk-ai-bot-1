EVENTS V44 — ОТВЕТЫ/ЦИТАТЫ VK И СУТОЧНЫЙ КОНТЕКСТ
=======================================================

В групповой беседе VK бот принимает прямое упоминание, ответ на его сообщение
и цитирование/пересылку его сообщения. Отдельная активная сессия для этого не
нужна.

В групповой беседе:

    доебись
    Гигорейв доебись
    Гигорейв доебаться
    Гигорейв докопаться
    Гигорейв фас
        Разово выбрать случайного активного участника и сделать игровую
        ситуативную прожарку по 20–60 его последним содержательным сообщениям.
        Сначала берутся последние 24 часа; если там меньше 20, история добирается.

    доебись <имя/@username>
    Гигорейв доебись <имя/@username>
    Гигорейв доебаться <имя/@username>
    Гигорейв докопаться <имя/@username>
    Гигорейв фас <имя/@username>
        Найти участника по имени, нику, транслиту или близкому написанию.
        Локальное совпадение от 90% считается найденным; при близкой ничьей
        выбирается тот, кто писал позже. Для прозвищ доступен ИИ-fallback.
        После выбора берутся 20–60 последних содержательных сообщений цели;
        при тихих последних сутках бот автоматически добирает более старую историю.

Роли «быдло», «дурачила»/«дурачина» и «политик» теперь изображаются заметнее
и слегка гипертрофированно. Адресная команда остаётся разовой: действуют
cooldown и запрет угроз, доксинга, реальных обвинений и травли по личным
признакам.

EVENTS V46 — ЛОКАЛЬНЫЕ ЭФЕМЕРИДЫ ДЛЯ ЛЮБОЙ МОДЕЛИ

    Гигорейв pro3 натал локалэфемериды 14.03.1987 19:40 Воронеж подробно
    Гигорейв pro2 прашна расчёт локально Москва <вопрос>

Ключи «локалэфемериды», «локальные эфемериды», «локал» и «расчёт локально»
принудительно включают максимальный локальный расчёт даже для pro/pro2/pro3.
Для mini/gpt54/gpt55 локальный maximum используется по умолчанию. Ключи
«нелокал», «без локального расчёта» и «не считай локально» отключают его.

Максимальный пакет передаётся модели без сокращения рассчитанных полей. В чат
технический JSON не выводится. Натал требует дату, точное местное время и место;
часовой пояс берётся по месту рождения либо указывается явно как IANA-зона.

EVENTS V42 — ГЛУБОКИЕ PRO-ОТВЕТЫ И ПОДРОБНАЯ ПРАШНА

    pro / pro2 / pro3 <запрос>
        Всегда глубокий, проверенный ответ до двух больших страниц.

    прашна <город и вопрос>
        Краткая интерпретация по максимальному локальному пакету maximum.

    прашна подробно <город и вопрос>
    прашна максимальный техрасчёт <город и вопрос>
    pro3 прашна <город и вопрос>
        Развёрнутый технический разбор без лимита 2–3 абзаца.

Локальные координаты, положения и хеш расчётного пакета больше не выводятся
отдельными сообщениями; пакет передаётся модели внутри запроса.

EVENTS V40 — АКТИВНОЕ ОБЩЕНИЕ И ДИАГНОСТИКА СОБЫТИЙ

В групповой беседе любой участник может включить режим:

    Гигорейв активное общение
    Гигорейв активное общение 10
    Гигорейв активное общение 100
    Гигорейв активное общение статус

Число задаёт размер окна. В каждом окне из N содержательных сообщений бот
заранее выбирает случайную позицию от 1 до N и отвечает ровно на неё. Поэтому
при N=10 это один случайный ответ среди каждых десяти сообщений, при N=100 —
один случайный ответ в пределах каждой сотни. Счётчик и выбранная позиция
хранятся в SQLite и не меняются после перезапуска процесса.

Для каждого самостоятельного ответа роль выбирается заново: лошара, дурачила,
обычный, интеллигент, учёный, хам или быдло. Грубая роль не означает, что бот
обязан хамить нейтральной реплике. Старые отдельные грубые фоновые outburst-
таймеры активным общением больше не включаются.

Отключение:

    Гигорейв активное общение отключить
    Гигорейв активное общение откл

Авторезюме, сохранённая модель поведения, интервал активного общения, счётчик
и выбранная случайная позиция хранятся в SQLite. Обновление файлов src/ и
перезапуск бота их не обнуляют.

При ручном добавлении ссылка на настоящее, но уже прошедшее мероприятие теперь
распознаётся отдельно. Оно не попадает в будущую афишу, а бот сообщает точную
причину и оставляет страницу открытой для проверки. Название, дата и место могут
подтверждаться несколькими точными цитатами страницы через разделитель ||.

EVENTS V39 — СОБЫТИЯ И МАНЕРА ОБЩЕНИЯ
=========================================

СТРОГАЯ АФИША
-------------
Событие попадает в базу только когда подтверждены одновременно:

    1. понятная суть мероприятия;
    2. календарная дата самого события;
    3. конкретное место проведения.

Время сообщения, имя, одиночная ссылка, товарная предпродажа и неясный фрагмент
не считаются событием. При запуске V39 старые записи без места и записи с
признаками недостоверного распознавания удаляются автоматически.

РУЧНОЕ ДОБАВЛЕНИЕ — ТОЛЬКО ВЛАДЕЛЕЦ
------------------------------------
В Telegram-ЛС владельца:

    ➕ Добавить информацию о событии

Во VK:

    добавить событие <описание или ссылка>

Ссылка открывается в постоянном браузере, страница слегка прокручивается и
остаётся открытой. Бот сравнивает текст со страницей. При ссылке без описания
событие сохраняется только после успешного чтения страницы.

НАСТРОЙКИ МАНЕРЫ ОБЩЕНИЯ — ЛЮБОЙ УЧАСТНИК
------------------------------------------

    теплота общения 1..10
    температура общения 9 из 10
    будь быдлом
    будь хамом
    будь лошарой
    будь дурачилой
    будь интеллигентом
    будь учёным
    будь политиком
    стиль общения
    сбрось стиль

Настройки сохраняются отдельно для текущего диалога. У «быдло» и «дурачила»
фоновые реплики идут через случайные 1–60 минут только при включённом
активном общении. Сценарий выбирается так:
40% — реакция на беседу целиком, 40% — выкрик в воздух, 20% — обращение к
участнику. Реплику генерирует случайная Luna или Terra; шаблон используется
только при ошибке модели. Перепалка начинается только после адресного сценария.

EVENTS V33 — МОДЕЛИ, НЕЛОКАЛЬНАЯ АСТРОЛОГИЯ И НАТАЛ
========================================================

Базовая модель по умолчанию: gpt-5.4-mini.

Ключи текстовых моделей можно ставить в любую позицию текстовой команды:

    mini / мини / база / эконом  -> gpt-5.4-mini
    gpt54 / стандарт            -> gpt-5.4
    gpt55 / классик             -> gpt-5.5
    pro / луна                  -> gpt-5.6-luna
    pro2 / терра                -> gpt-5.6-terra
    pro3 / сол                  -> gpt-5.6-sol

Примеры:

    Гигорейв gpt54 объясни тему
    Гигорейв pro2 резюмируй 500 сообщений
    Гигорейв pro3 проанализируй всю конфу
    Гигорейв mini нарисуй нашу конфу

Изображение всегда создаёт gpt-image-2; ключ выбирает текстовую модель, которая
готовит резюме, анализ конфы или уточнённый промпт.

pro/pro2/pro3 могут отвечать до двух больших страниц и во VK, и в Telegram.
Этот объём может быть автоматически разделён на несколько сообщений. Обычное
правило 8–10 предложений к pro не относится. Если запрошено 10 000 слов или
другой заведомо больший объём, бот молча выдаёт лучший законченный вариант в
пределах двух страниц, а не спорит о лимите и не предлагает другой формат.
mini, gpt54 и gpt55 обычно дают не больше двух средних абзацев; ключ «подробно»
разрешает 4–5 абзацев.

Прашна без ключа модели использует gpt-5.4-mini и максимальный локальный пакет.
pro/pro2/pro3 по умолчанию считают внутри модели, но «локалэфемериды», «локал»
или «расчёт локально» принудительно включают тот же maximum-пакет. «Нелокал»,
«без локального расчёта» и «не считай локально» отключают локальный движок.

«Натал» и «натальная карта» не считаются прашной. Для локального натала нужны
дата, точное местное время, место рождения и надёжный часовой пояс места.

TELEGRAM

В ЛС Telegram слово «Гигорейв» не требуется.
В группе: «Гигорейв <запрос>», «@username_бота <запрос>», /help или ответ на сообщение бота.
/id — показать telegram_chat_id и telegram_user_id.
Прашна доступна в VK. В Telegram команда прашны намеренно отключена и не показывается в /start, /help и подсказках.

СЛУЖЕБНОЕ СКАНИРОВАНИЕ ПАМЯТИ
-----------------------------
Только владелец и только в ЛС:

    сканируй базу на запомни

Дополнительные варианты:

    сканируй на запомнить
    просканируй всю базу сообщений на команду запомни
    пересобери память из базы

Сканирование запускается только этой командой. При старте бота оно не
выполняется. Бот читает всю таблицу messages, переносит настоящие исторические
команды «запомни», «запоминай», «сохрани в память» и аналоги в explicit_memories и выводит количество новых, обновлённых
и пропущенных записей.

«Запомни это» из старой базы пропускается: таблица messages не хранит
reply_message, поэтому восстановить исходную реплику нельзя.

ЯВНАЯ ПАМЯТЬ
------------
В беседе:

    Гигорейв запомни <текст>
    Гигорейв запоминай <текст>
    Гигорейв сохрани в память <текст>
    Гигорейв запомни это   (ответом на нужную реплику)

Удаление в беседе:

    Гигорейв распомни <ключ>
    Гигорейв разпомни <ключ>
    Гигорейв забудь про <тему>
    Гигорейв удали из памяти <ключ>

В ЛС те же команды работают без слова «Гигорейв».

При удалении бот убирает все активные определения, упоминания и связанные
записи по ключу только в текущем peer_id. Обычная история сообщений не
удаляется. Забытые записи не возвращаются при служебном сканировании базы.

Память изолирована по peer_id. Обычные сообщения ЛС на диск не сохраняются.

НЕСТАНДАРТНЫЕ ТЕРМИНЫ
----------------------
Перед основным GPT-ответом бот служебным запросом выделяет вымышленные, локальные,
жаргонные и другие неочевидные термины. Затем ищет их определения в явной памяти
текущего диалога и передаёт найденное в основной GPT-запрос.

НАТАЛЬНАЯ КАРТА
• Гигорейв mini натал <дата, точное время, место и вопрос> — локальный packet=maximum.
• Гигорейв pro/pro2/pro3 натал <данные и вопрос> — model-only по умолчанию.
• Добавьте «локалэфемериды», «локал» или «расчёт локально», чтобы pro тоже получил maximum-пакет.
• Натальный ответ всегда развёрнутый. «Нелокал» отключает локальный расчёт для любой модели.

    будь хамом

Настройки сохраняются отдельно для текущего диалога. Теплота — это подача

EVENTS V55 — АНАЛИЗ ИЗОБРАЖЕНИЙ ВСЕМИ GPT-МОДЕЛЯМИ
====================================================

Без ключа:
    Гигорейв что на картинке
запускает GPT_MODEL_DEFAULT / gpt-5.4-mini.

Явный ключ выбирает стартовую модель:
    mini / gpt54 / gpt55 / pro / pro2 / pro3

После первого временного отказа та же модель повторяется через случайные
5–30 секунд. После второго отказа анализ переходит по цепочке:
    gpt-5.4-mini -> gpt-5.4 -> gpt-5.5 -> Luna -> Terra -> Sol.

Технические 400/404/429/5xx и request id пользователю не показываются.
gpt-image-2 создаёт новые изображения, но не анализирует входящие картинки.

V136 alias парсера:
    тусы парсер все
        Полный эквивалент «парсер все»; имеет приоритет над показом списка тус.


Владелец (ЛС): обращения сегодня / обращения неделя / обращения 3 дня / обращения за прошлые 4 дня; тусы дубли проверить / тусы дубли статус / тусы дубли применить.
