ИЗМЕНЕНИЕ: выбор модели для джйотиш-прашны

Теперь прашна может обрабатываться двумя моделями:

  Гигорейв gpt pro2 прашна ...  -> GPT pro2 / Terra
  Гигорейв gpt pro3 прашна ...  -> GPT pro3 / Sol

Без явного режима:

  Гигорейв прашна ...
  Гигорейв gpt прашна ...
  Гигорейв gpt pro прашна ...

прашна по-прежнему направляется в GPT pro3, чтобы базовая модель и Luna
не интерпретировали большой технический пакет Swiss Ephemeris.

Локальный расчёт эфемерид выполняется до запроса к GPT для обоих режимов.
Примечание: это историческое описание. Начиная с Events V13 потоковая передача включена по умолчанию.
