Gigorave V151
==============

1. Рекомендуемый Node.js: >=24 (как указано в package.json).
2. Распаковать full-архив поверх отдельной папки проекта либо применить patch к чистому V150.
3. Установить зависимости обычной для проекта командой pnpm/npm.
4. Запустить: npm run verify
5. После успешной проверки запускать бота штатной командой npm start.

SQLite обновляется мягко: в telegram_source_posts и vk_source_posts автоматически добавляются text_fingerprint и image_fingerprints_json. Исходные события и история не должны удаляться этой миграцией.

Важно: команда выдачи «тусы ...» теперь принципиально не восстанавливает картинки на лету. Если афиши не было сохранено парсером/maintenance-проходом, пользователю уйдёт текстовая карточка без картинки.
