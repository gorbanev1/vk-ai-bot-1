УСТАНОВКА EVENTS V47

Сборка: events-v47-gpt-retry-identity-retort
Базовая версия: полный V46

1. Остановить бота.
2. Сделать резервную копию проекта, .env, data и браузерного профиля.
3. Распаковать V47 поверх полного V46 с заменой файлов.
4. Выполнить npm install или pnpm install, если зависимости ещё не установлены.
5. Выполнить npm run verify.
6. Запустить npm start.

Миграция SQLite не требуется.
.env, data, bot.sqlite и браузерный профиль в патч не входят и не должны
перезаписываться.
