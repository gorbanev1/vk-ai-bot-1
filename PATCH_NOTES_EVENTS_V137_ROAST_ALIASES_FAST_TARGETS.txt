Gigorave V137 — обе команды доёба + быстрый поиск цели
=====================================================

Исправлено по реальному VK-кейсу:

1. Обе формы теперь считаются равноправными локальными командами:
   - гигорейв доебись Денни
   - гигорейв доебаться @deoko
   Также: доебайся, доебывайся, докопаться, докопайся, фас.

2. Адресный доёб по имени больше НЕ ждёт полного состава VK-беседы.
   Сначала используется уже сохранённая история/участники чата. Это убирает
   зависание на getConversationMembers в больших беседах.

3. @username / id / VK-ссылка по-прежнему резолвятся напрямую, но lookup
   теперь имеет жёсткий таймаут 3.5 секунды. При сбое команда не зависает:
   ниже остаётся name-only fallback, поэтому ответ всё равно может уйти.

4. Полный roster VK оставлен только там, где он действительно нужен — прежде
   всего для случайной команды без указанной цели.

5. Telegram detector обновлён теми же алиасами, чтобы вложение/картинка не
   уводили команду в vision-маршрут.

Проверено:
- точные две команды со скриншота;
- V135/V136 roast regression;
- Telegram routing;
- command priority routing;
- syntax/import checks.
