# V188.150: будущие афиши и ожидание AI

Основа: последняя рабочая V188.149 (потоковый обход будущих событий, режимы `тусы обновить будущие` и `тусы обновить будущие безфото`/`бф`).

Исправлено: запросы Vision и текстового разбора событий больше не прерываются локальным таймаутом HTTP 15–180 секунд в `botApplication.js`; при получении HTTP 403 транспорт не делает второй POST к той же модели только ради замены stream/non-stream, а передаёт отказ существующей лестнице моделей/ключей. При этом не отключены ручная остановка владельцем и существующие правила обработки отказа провайдера, проверки принадлежности фото, ограничения параллельности, сохранение локального захвата источника и журнал ошибок. Astra/TXT streaming не изменён.

Важно: браузер имеет отдельные проверки доступности страницы, а у внешнего роутера могут быть собственные сроки и отказы. Нельзя гарантировать успешный Vision или картинку у всех событий. Реальные API-запросы в тестах не выполнялись.

Команда `тусы обновить будущие`: открывает ссылки всех будущих карточек с интервалом 5–16 секунд и ставит захваченный источник в независимую AI-очередь. `тусы обновить будущие бф`: те же открытия, но обновляет только карточки без подтверждённой афиши. Обычный `тусы парсер все` не изменён.
