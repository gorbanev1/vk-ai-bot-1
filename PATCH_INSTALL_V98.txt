Установка V98 поверх текущего проекта
======================================

1. Остановите единственный запущенный процесс бота.
2. Скопируйте файлы из patch-архива в корень проекта с заменой.
3. Не заменяйте свой .env и не копируйте чужой data/bot.sqlite.
4. Выполните:

   pnpm install --frozen-lockfile
   pnpm verify
   pnpm start

Если V97 ещё не ставился, этот patch уже содержит необходимые файлы V97
для таблицы coords_override_settings, маршрута команд и fast-path.
CREATE TABLE IF NOT EXISTS не удаляет старую базу, историю или события.

Настройка сообщения
===================

Со своего owner-профиля:

   корды сообщение

Бот ответит:

   Введите сообщение.

Следующее текстовое сообщение сохраняется дословно и включает режим.
Повторная настройка заменяет старый текст.

Проверка владельцем
===================

После сохранения владелец может В ЛЮБОЕ ВРЕМЯ получить этот текст командами:

   корды
   корды пересоздание
   корды случайное пересоздание

Это работает и до 22 августа. Для владельца эти команды проходят через
абсолютный fast-path до DM notice и GPT, поэтому ответ — только сохранённый текст.

Для остальных пользователей
============================

Специальная выдача действует только:

   22 августа 2026, Europe/Moscow
   начало: 12:00:00 включительно
   конец:   24:00:00 (00:00 23 августа уже не входит)

В это окно те же три точных запроса получают только сохранённый текст.

Управление
==========

   корды отключить
       выключает специальную выдачу и для владельца, и для остальных,
       но сохраняет текст в SQLite.

   корды удалить
   корды удалить сообщение
   удалить сообщение
       удаляют текст и выключают режим.

Новая команда «корды сообщение» после сохранения нового текста снова включает режим.

Проверка случайных ответов в ЛС
===============================

Три канонических FAQ-ответа о ближайшей тусе (дата / формат / подробности)
не выбираются случайно: они требуют явного вопроса о конкретной или следующей тусе.

Отдельно в боте есть DM AI notice. Он показывается на первом сообщении в ЛС,
а затем повторяется через случайный интервал 1–7 дней. В его тексте есть подсказка
про ближайшую тусу и афишу, поэтому пользователь может воспринимать его как
«рандомный ответ про тусу». Это дополнительное сообщение, после него обычный
запрос всё равно маршрутизируется дальше. V98 этот общий notice не удаляет.
