V78 — EVENT NORMALIZATION / TELEGRAM IMAGE MODE+QUOTA / OWNER INGEST

1. Афиша перед выдачей проходит через GPT-редактора.
   - Из источника берутся только факты.
   - Удаляются UI-строки VK/Telegram, реакции, хэштеги, ссылки из тела анонса, дубли Когда/Что/Кто/Где/Почем и редакционный мусор.
   - Цена очищается от шуток, но условия входа сохраняются.
   - Диапазон дат сохраняется, если он явно есть в сыром источнике.
   - Часть даты 07.08 не должна становиться временем 07:08.
   - Если поле неизвестно — оно не выводится. Если источник прямо обещает сообщить место позже, эта формулировка сохраняется.
   - Итоговый формат: название, дата/диапазон, время/расписание, тип, место, участники, цена, короткий связный анонс, источник.
   - Старые строки SQLite тоже очищаются при выдаче; миграция базы для этого не нужна.

2. Owner-ingest событий.
   - Материал владельца считается заведомо событием и повторно не отбрасывается классификатором event/not-event.
   - Для ссылки браузер подгружает видимые посты страницы (до 25 кандидатов).
   - GPT выбирает ровно один основной пост. Соседние публикации не объединяются.
   - До 4 изображений основного поста анализируются vision-моделью; факты с афиши участвуют в извлечении.
   - Основная картинка поста сохраняется для события, если её удалось скачать.
   - В базу идёт максимум одно очищенное событие. Дата обязательна для календарного индекса; время, место, участники и цена необязательны.

3. Telegram gpt-image-2.
   - Обычный пользователь: 2 фактических вызова gpt-image-2 в сутки.
   - Счётчик общий между Telegram ЛС и Telegram-группами для одного пользователя.
   - Владелец unlimited.
   - VK сохраняет GPT_IMAGE_DAILY_LIMIT (по умолчанию 5).
   - Редактирование существующей картинки через gpt-image-2 теперь правильно списывает image-квоту, а не текстовую.

4. Telegram image mode.
   - Кнопка «🖼 Изображение» включает постоянный режим.
   - Любой обычный текст в режиме становится промптом изображения.
   - После одной генерации режим НЕ сбрасывается.
   - Выход: другой пункт меню или явная не-image команда.
   - «рисуй», «нарисуй», «сделай картинку», «создай изображение» и аналоги всегда имеют приоритет генерации независимо от состояния меню.

5. Справка.
   Отдельные профили проверяются для:
   - владельца (VK/Telegram ЛС, owner-only раздел + unlimited image);
   - VK ЛС;
   - Telegram ЛС;
   - VK-конфы;
   - Telegram-группы.
   Telegram ЛС теперь показывает и прашну, и натал, а не урезанный natal-only раздел.
