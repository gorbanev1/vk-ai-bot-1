Events V31 — Telegram Bot API

- Добавлен одновременный запуск VK и Telegram в одном Node.js-процессе.
- Telegram работает через официальный HTTP Bot API и long polling getUpdates без новой npm-зависимости.
- Добавлены TELEGRAM_BOT_TOKEN и TELEGRAM_OWNER_USER_ID.
- ЛС Telegram маршрутизируются как ЛС VK; группы требуют обращения к боту, @username, команды или ответа боту.
- Сообщения групп Telegram сохраняются в общую SQLite-базу для резюме, анализа конфы и памяти.
- Добавлена таблица platform_identities, исключающая коллизии VK и Telegram ID.
- GPT, pro/pro2/pro3, прашна, память, афиша, изображения и GigaChat-команды используют общее ядро.
- GPT-картинки и картинки афиши отправляются в Telegram через sendPhoto; файлы больше 10 МБ — через sendDocument.
- /id показывает реальные telegram_chat_id и telegram_user_id.
- Offset Telegram обновлений сохраняется на диск, чтобы не повторять обработанные сообщения после перезапуска.
- Автозапуск скрейперов не изменён: все источники по-прежнему запускаются только вручную.
