Gigorave V188.40

1. Fixed dossier routing when the word “досье” appears after the participant name.
   Supported examples:
   - Гигорейв досье Иван
   - Гигорейв Иван досье
   - Гигорейв Иван полное досье
   - Гигорейв досье на Иван

2. The command is canonicalized before target resolution, so fuzzy participant lookup receives only the participant name.

3. Normal dossier output now gets a dedicated final render targeting about 2000 characters. Preferred range: 1800–2200 characters when enough evidence exists. The model must not invent padding when evidence is weak.

4. Compact final dossier has a separate cache variant (compact-v18840), so stale short portraits from older versions are not reused as the final answer. Existing accumulated facts and paid-batch checkpoints are preserved.

5. Full dossier mode remains separate.
