Gigorave V187.1 installation
============================

Если у вас уже установлен V187:
1. Остановите bot process / pnpm dev.
2. Распакуйте Gigorave_V1871_patch.zip В КОРЕНЬ проекта с заменой файлов.
3. Не удаляйте data/, .env и рабочую bot.sqlite.
4. Запустите pnpm dev.

При успешном старте в логе должно быть:
  [BOT BUILD] events-v1871-image-selection-export-hotfix
  [BOT PATCH] events-v1871-image-selection-export-hotfix

Для чистой установки можно использовать Gigorave_V1871_full_sources.zip.

V187.1 не требует перепарсивать уже обработанные события и не сбрасывает
V187 personalization checkpoints.
