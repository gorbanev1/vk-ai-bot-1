V112 — статистика запросов координат

Новые owner-команды:
- «сколько запросило корды» — возвращает только количество уникальных пользователей. Повторные запросы одного пользователя не увеличивают число; один VK ID, встречавшийся в двух VK endpoint, считается один раз. Telegram и VK считаются разными платформенными идентичностями.
- «корды юзернеймы» — отправляет двумя сообщениями два списка: Telegram и VK. Telegram показывает @username, VK — vk.com/screen_name. Если username недоступен, показывается platform ID.

Технически:
- coords_request_recipients мягко расширена колонкой external_username; существующая SQLite не очищается.
- Telegram username сохраняется при новых запросах и для старых записей при необходимости запрашивается через Bot API getChat.
- VK screen_name подтягивается через users.get по сохранённым VK ID.
- существующая логика координат/QR и рассылки не изменена.
