V62 OWNER-ONLY DOSSIER — УСТАНОВКА

1. Остановите бота.
2. Наложите patch-архив V61 -> V62 поверх папки проекта либо распакуйте полный V62 в новую папку.
3. Сохраните существующие .env и data/. Новых переменных окружения и миграций SQLite нет.
4. Выполните:
   pnpm install --frozen-lockfile
   pnpm verify
   pnpm dev

Команда «досье» доступна только владельцу бота. Посторонние получают «Команда недоступна.» без запроса пароля и без чтения базы.
