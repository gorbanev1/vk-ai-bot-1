Gigorave Bot V141
=================

1. Остановите текущий процесс бота.
2. Сделайте резервную копию .env и data/bot.sqlite.
3. Распакуйте полный архив V141 поверх каталога приложения или используйте patch-архив.
4. Верните свой .env и data/bot.sqlite, если устанавливаете в чистую папку.
5. Выполните npm install / pnpm install, если зависимости ещё не установлены.
6. Запустите npm run check:syntax и npm run test:v141.
7. Запустите бота обычной командой.

V141 не требует миграции БД. Настройки авторезюме и накопленная история остаются прежними.

Изменение V141: авторезюме теперь 1600–2400 знаков, обычно 5–7 коротких абзацев, без подробной стенограммы каждой ветки.
Все исправления V140 по обновлению существующих VK-анонсов включены.
