EVENTS V42 — УСТАНОВКА ПАТЧА
================================

Патч накладывается поверх полного проекта V41.

1. Полностью остановите bot/node --watch.
2. Сохраните копии:

   Copy-Item .env .env.backup
   Copy-Item data data.backup -Recurse

3. Распакуйте содержимое папки vk-ai-bot из patch поверх текущего проекта с заменой файлов.
4. Выполните:

   pnpm install --frozen-lockfile
   pnpm verify
   pnpm dev

Ожидаемая строка запуска:

   [BOT PATCH] events-v42-deep-pro-hidden-full-astrology

Патч не содержит .env, рабочую SQLite-базу, data, node_modules или браузерный профиль.
