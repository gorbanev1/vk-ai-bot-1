V93 — двухконтурное объединение одного события из разных источников

1. Останови бота.
2. Распакуй V93 поверх текущего проекта V92.
3. Не удаляй и не заменяй .env, data/, SQLite и browser profile.
4. Установи зависимости при необходимости:
   pnpm install --frozen-lockfile
5. Проверка нового алгоритма:
   pnpm run test:event-two-contour
6. Запуск:
   pnpm dev

Ожидаемая сборка:
[BOT BUILD] events-v93-two-contour-event-deduplication

Как работает:
- контур 1 без ИИ сравнивает дату, время, площадку, название и участников;
- очевидные совпадения объединяются сразу;
- очевидные различия не отправляются в ИИ;
- только серая зона отправляется в gpt-5.4-mini как второй контур;
- при объединении сохраняются все источники и объединяются неповторяющиеся факты описаний.
