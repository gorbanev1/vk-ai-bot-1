V63 SCRAPER HELP AND RUN ALL — УСТАНОВКА

1. Остановите бот.
2. Наложите patch-архив V62 -> V63 поверх папки проекта либо распакуйте полный V63 в новую папку.
3. Сохраните свои .env, data/, SQLite-базу, браузерные профили и токены.
4. Выполните:
   pnpm install --frozen-lockfile
   pnpm verify
   pnpm dev

Новых npm-зависимостей, переменных .env и миграций SQLite нет.

Новые команды владельца:
- Гигорейв парсер
- Гигорейв парсер все
- Гигорейв парсер запустить <source-id>
