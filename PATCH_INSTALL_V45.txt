УСТАНОВКА EVENTS V45
====================

Сборка: events-v45-cynical-active-luna-terra-outbursts
База: полный проект V44 либо полный проект, на который уже наложены V42–V44.

1. Остановить бота.
2. Сделать резервную копию:
   - .env;
   - data/bot.sqlite;
   - data/scraper-browser-profile;
   - всей рабочей папки проекта.
3. Распаковать архив поверх проекта с заменой файлов.
4. Не удалять .env и data/. Они не входят в архив и не должны перезаписываться.
5. Выполнить:

   pnpm install --frozen-lockfile
   pnpm verify
   pnpm start

6. Проверить строку сборки:

   [BOT PATCH] events-v45-cynical-active-luna-terra-outbursts

7. В тестовой группе выполнить:

   Гигорейв будь быдлом
   Гигорейв стиль общения
   Гигорейв активное общение

Статус должен показать интервал 1 минута–1 час и веса 40%/40%/20%.
В логах автономных реплик должны появляться modelMode=pro либо modelMode=pro2.

Схема SQLite не меняется. При первом старте расписания старого диапазона,
стоящие дальше одного часа, автоматически переносятся внутрь нового окна.

Архив не содержит .env, токены, рабочую SQLite-базу и браузерный профиль.
