УСТАНОВКА EVENTS V52

Сборка: events-v52-reply-target-analysis
Базовая версия компактного патча: V51 events-v51-active-communication-master-switch

1. Остановить бот.
2. Сделать резервную копию проекта, .env, data/bot.sqlite и браузерного профиля.
3. Полный архив можно распаковать поверх проекта с заменой исходников.
4. Компактный patch-from-v51 применять только к чистой V51.
5. Не заменять свой .env, data/, data/bot.sqlite и авторизованный браузерный профиль.
6. Выполнить:

   npm install
   npm run verify
   npm start

7. В логе должна появиться строка:

   [BOT PATCH] events-v52-reply-target-analysis

8. Ручная проверка:

   - во VK ответить на чужое сообщение фразой «Гигорейв, оцени это сообщение»;
   - повторить в Telegram;
   - убедиться, что ответ разбирает исходную реплику, а не текст команды;
   - проверить сообщение с текстом и ссылкой/вложением;
   - проверить обычный вопрос без reply: поведение должно остаться прежним.

Новая миграция SQLite и новые переменные окружения не требуются.
