# Gigorave V188.98 — исправление текста и афиши одной карточки

## Что исправлено

1. `тусы исправить <название>` теперь принимает после выбора не только новый текст, но и новую картинку либо текст + картинку одним сообщением.
2. Новая картинка не записывается вслепую: Vision извлекает дату/название/участников, затем poster matcher проверяет её именно против выбранной/исправленной карточки. Несовпадающая афиша отклоняется без изменения события.
3. Текстовая правка больше не может оставить старую «безопасную» афишу от другого события. Если изменились дата/название/участники/площадка, сохранённая Vision metadata повторно проверяется; несовместимая привязка переводится в `poster_review_required` и перестаёт показываться, при этом исходный файл/metadata не уничтожаются.
4. Публичная отправка получила дополнительную защиту: если у выбранной сохранённой картинки есть Vision facts, `eventHasSafePosterMatch()` заново проверяет их против текущей карточки перед показом. Старый `exact_poster_match` сам по себе больше не перекрывает явный metadata-конфликт.
5. Owner replacement сохраняет новую локальную source-картинку, её hash/Vision metadata и `poster_image_index`, после чего verified snapshot инвалидируется и перестраивается.

## Как пользоваться

- `тусы исправить Праздник урожая`
- если вариантов несколько: `исправить 1`
- затем можно отправить:
  - только новый текст;
  - только правильную афишу;
  - новый текст + правильную афишу одним сообщением.

Если картинка содержит другую дату/другое событие, бот её не привяжет.
