V68 — NVIDIA account-aware model probe and full test

Причина патча
-------------
NVIDIA GET /v1/models возвращает общий каталог. Наличие model id в этом каталоге не гарантирует, что соответствующая serverless function назначена конкретному аккаунту. Поэтому ключ мог успешно пройти GET /models, а POST /chat/completions для выбранной модели возвращал:

HTTP 404: Function '...' Not found for account '...'

Это не ошибка ключа. В V67 команда «тест авто» выбирала одну вероятную chat-модель и останавливалась на первом 404.

Что исправлено
--------------
1. «Гигорейв api nvidia тест авто» теперь перебирает до 30 chat/instruct-моделей и пропускает account-specific HTTP 404 до первой реально рабочей.
2. «Гигорейв api nvidia запрос авто <текст>» использует ту же проверку и не требует model id.
3. Добавлена команда «Гигорейв api nvidia рабочая модель».
4. Добавлены команды «Гигорейв api nvidia автотест» и «Гигорейв api nvidia полный тест».
5. Полный тест сам находит рабочую модель и выполняет пять готовых запросов: точный ответ, арифметика, JSON, перевод и JavaScript.
6. «Гигорейв api nvidia примеры» сначала находит реально работающую модель и затем выдаёт готовые команды с её точным model id.
7. Вывод показывает модели, пропущенные из-за 404, и объясняет, что ключ при этом исправен.
8. Автовыбор больше не ставит старую крупную Nemotron-модель выше небольших базовых instruct-моделей только из-за слова nemotron.
