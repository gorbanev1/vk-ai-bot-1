EVENTS V26 — ОБЪЕДИНЕНИЕ ДУБЛЕЙ МЕРОПРИЯТИЙ
============================================

Что изменено
------------
1. Перед выдачей афиши события из Telegram, VK-пабликов и VK-бесед проходят
   общую сверку и собираются в канонические группы.
2. Дата должна совпадать точно. Затем сравниваются:
   - время;
   - название;
   - участники;
   - площадка;
   - текст анонса;
   - ссылка источника.
3. Одна дата, время или ссылка сами по себе не считаются достаточными. Нужен
   смысловой якорь, поэтому разные мероприятия на одной площадке не склеиваются.
4. При объединении сохраняются:
   - наиболее содержательный заголовок;
   - более полный текст;
   - место, время и цена;
   - объединённый список участников;
   - все неповторяющиеся изображения;
   - все нормальные публичные источники.
5. Персональные ссылки на VK-беседы по-прежнему не публикуются.
6. Алгоритм применяется при чтении афиши, поэтому сразу скрывает и старые
   дубли, уже находящиеся в data/bot.sqlite. Исходные записи не удаляются:
   это позволяет не потерять фотографии и ссылки разных анонсов.

Диагностика
-----------
При первом обнаружении каждой пары в консоли появляется:
[EVENT DEDUPE MERGE] date=... score=... reasons=... title=...

Проверка
--------
npm run test:event-dedupe
npm test

-----------------------
