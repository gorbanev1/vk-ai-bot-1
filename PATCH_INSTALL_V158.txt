PATCH V157 -> V158

Распакуйте содержимое архива поверх рабочей папки V157 с заменой файлов.
.env и runtime-каталоги/data патч не содержит и не должен перезаписывать.

После обновления:
1. npm install — только если это требуется вашей установкой;
2. npm start;
3. проверить: авторезюме статус все;
4. проверить ручной парсер: запустить источник и закрыть все окна Chromium — проход должен завершиться без повторного открытия браузера;
5. проверить Telegram-меню: Изменить изображение, Документы, Назад/Главное меню;
6. для проблемного поста с несколькими афишами заново пропарсить источник: события должны разделиться, а каждой карточке должна соответствовать своя картинка.
