Version: 0.187.2

FIX 1 — «Гигорейв резюмируй 12000»
- Old code split by only 18,000 characters, causing dozens of sequential GPT calls plus merge calls.
- V187.2 groups explicit summary input into stable day-aligned batches capped at 500 messages / 90,000 chars.
- Each leaf and merge stage is stored in durable content-addressed cache:
  %LOCALAPPDATA%\Gigorave\state\summary-v1872.sqlite
- Exact repeated work is cache-hit and does not call GPT again.
- When a rolling range changes, stable completed day/batch blocks remain reusable; only changed edge/current blocks need regeneration.
- Logs: [SUMMARY V1872 PLAN], [SUMMARY CACHE HIT], [SUMMARY CACHE STORE], [SUMMARY V1872 COMPLETE].

FIX 2 — dossier misses predecessor-chat history
- Old V187 dossier used getAllMessages(peerId) only.
- V187.2 unions canonical messages with vk_message_archive rows for the target user.
- Physical source_peer_id is preserved, so linked old chat history is visible.
- Archive-only users are included when resolving `досье <name>`.
- Dossier checkpoints are now per source peer. A V187 checkpoint from the new chat cannot suppress older messages discovered later from the predecessor chat.
- Logs: [DOSSIER HISTORY SOURCES] shows sourcePeerId:messageCount.

FIX 3 — repeated history recovery on every restart
- Local backup SQLite scan now has durable external state:
  %LOCALAPPDATA%\Gigorave\state\history-recovery-v1872.sqlite
- Normal restart skips that scan when current bot.sqlite still has at least the checkpointed message count and linked-source configuration is unchanged.
- Rollback/replacement to a smaller bot.sqlite automatically enables recovery again.
- `VK_FORCE_LOCAL_HISTORY_SCAN=1` forces a local rescan.
- A previously successful CMID fallback no longer re-tests the known-denied getHistory endpoint.
- Completed CMID recovery starts after the previous ceiling; the previous 500 IDs are not replayed.

Preserved from V187/V187.1:
- dossier only on explicit command;
- no daily/startup dossier GPT backfill;
- communication style waits for 500 new user messages;
- no event reparse solely because parser version changed;
- V186 remote image fingerprint retry/fallback;
- V187.1 missing named-export hotfixes.
