# Установка V188.142 и проверка всех 16 источников

Этот ZIP — накопительное обновление к существующему Gigorave: в нём кодовые файлы и тесты предыдущих V188.130–141 плюс V188.142. Он НЕ полный автономный репозиторий: остальные файлы исходного проекта остаются у владельца. **Не распаковывать в пустую папку и не удалять data, .env или браузерный профиль.** Останови работающий бот, сделай резервную копию кода и data (включая SQLite WAL/SHM), затем распакуй поверх корня проекта с заменой кодовых файлов. Проверь свои локальные изменения, если есть.

После перезапуска одна команда «Гигорейв парсер всё» запускает обычный pipeline захват → admission → Vision/AI → события и афиши. Для каждого VK-источника старт запланирован через 10–20 с после **старта** предыдущего VK, а не после завершения c22. Беседа c22 в общем проходе ограничена 20 сообщениями без дополнительного history-backfill; индивидуальная команда беседы не изменена. Общая обработка кандидатов всё ещё ожидает raw-cache от каждого источника, но у VK-бесед есть временной предел с явной отметкой неполного результата.

В консоли сохрани `[PARSER ALL SOURCES CONFIGURED]` и `[PARSER ALL SOURCE OPEN START]` / `[PARSER ALL SOURCE FINISHED]` / `[PARSER ALL SOURCE FAILED]`. В `data/parser-forensic-archives/<runId>/trace.jsonl` сохрани события `run.source-registry`, `run.source-count-mismatch` (если есть), `source.run.scheduled`, `source.vk.open-gap`, `source.run.start`, `source.capture.complete`, `source.run.finish`, `source.run.error`, `run.capture.complete`. Если список не содержит ожидаемые 16 source IDs, причина в реестре/конфигурации/флагах включения, а не в прокрутке c22; архив не может самостоятельно восстановить удалённые настройки.

После полного прохода в том же `data/parser-forensic-archives/<runId>/` сохраняются `vk-dom-final-snapshots/`, poster-forensics и другие прежние артефакты. Старую папку снимков удалять не нужно. Если c22 достигла 3-минутного ограничения, в итоговом статусе она отмечена как неполная и это **не** гарантия, что 20 сообщений считаны.

Проверка без живого VK:

`node --test tests/scrapers/v188142AllSourcesLaunch.test.mjs tests/scrapers/v188141NativeDomCheckpoints.test.mjs tests/scrapers/v188140VkFinalDomSnapshot.test.mjs`

Тест запусков имитирует **16 источников и незавершённый c22**; он проверяет последовательность и интервал на подставных часах, но НЕ доказывает запуск 16 живых вкладок на вашем компьютере. Для самостоятельного аудита включён `AUDIT_V188142_SOURCE_PIPELINE_RU.txt`, рядом находятся реальные изменённые модули.
