EVENTS V29 — ИМПОРТ ИСТОРИЧЕСКИХ «ЗАПОМНИ» И РАЗДЕЛЁННАЯ СПРАВКА
=================================================================

1. Ручное сканирование базы памяти
----------------------------------
Добавлена служебная команда владельца:

    сканируй базу на запомни

Также распознаются формулировки:
- сканируй на запомнить
- просканируй всю базу сообщений на команду «запомни»
- пересобери память из базы

Команда принимается только от VK user_id 755496806 и только в личных
сообщениях бота. Автоматического сканирования при старте нет.

2. Что именно сканируется
-------------------------
По служебной команде бот читает всю таблицу messages во всех сохранённых
беседах. Для каждого сообщения со словом «запомни» он проверяет, является ли
оно настоящей командой памяти, включая формы:

    Гигорейв запомни <текст>
    [club...|Гигорейв] запомни <текст>

Случайные фразы вроде «он сказал мне запомни этот день» не импортируются.

В explicit_memories записываются:
- исходное сообщение целиком;
- полезная часть после команды «запомни»;
- peer_id беседы;
- автор исходного сообщения;
- conversation_message_id;
- исходная дата сообщения.

Повторный запуск безопасен: уникальная пара peer_id + conversation_message_id
обновляется, а не создаёт дубль.

Исторические команды «запомни это» пропускаются, потому что старая таблица
messages не хранит reply_message и невозможно надёжно определить исходную
реплику. Результат сканирования показывает количество проверенных, созданных,
обновлённых и пропущенных записей.

3. Разделение справки
---------------------
В групповой беседе команда «Гигорейв помощь» показывает только команды,
которые применимы в групповой беседе.

В ЛС обычного пользователя «помощь» показывает только команды личного диалога.
Команды анализа истории конфы, статистики беседы и служебные команды владельца
там не выводятся.

В ЛС владельца показывается полный список, разделённый на три группы:
- команды групповой беседы;
- команды личных сообщений;
- служебные команды владельца.

Служебные команды владельца никогда не показываются в справке группового чата.
