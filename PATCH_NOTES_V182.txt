Gigorave V182 — leaver periods, restart-safe auto reports, participant DM broadcast

LEAVER REPORT PERIODS
- Manual commands now support:
  - `Гигорейв кто вышел сегодня` — from local 00:00 Europe/Moscow to now.
  - `Гигорейв кто вышел день` — rolling last 24 hours.
  - `Гигорейв кто вышел N дней` — rolling N×24 hours (1..365).
  - `Гигорейв кто вышел неделя` — rolling last 7 days.
  - `Гигорейв кто вышел на этой неделе` — current calendar week from Monday 00:00 Europe/Moscow.
- `список кто вышел ...` accepts the same period suffixes.
- Every result keeps V181 clickable VK-native names (`[id123|Имя Фамилия]`) and exact exit/kick timestamps.

AUTOMATIC LEAVER REPORTS
- Owner-only configuration in the target VK conversation:
  - `Гигорейв кто вышел авто день`
  - `Гигорейв кто вышел авто N дней`
  - `Гигорейв кто вышел авто неделя`
  - `Гигорейв кто вышел авто статус`
  - `Гигорейв кто вышел авто выкл`
- The interval starts when enabled. When the interval elapses, the bot posts the report into the same conversation automatically.
- State is durable in `bot.sqlite` table `chat_leaver_auto_settings`; restart does not reset the interval or silently drop the accumulated window.
- If the bot was offline past the due time, the next run covers from the last successfully reported boundary to the current run, then schedules the next interval.

OWNER PARTICIPANT DM BROADCAST
- `Гигорейв лс участникам <текст>` sends the text to all current VK conversation members that the community is allowed to message privately.
- `Гигорейв лс участникам активным N дней <текст>` intersects the current roster with users who have messages in the durable chat history during the last N days.
- Command is owner-only and must be issued in the target VK conversation.
- Delivery is sequential with a short delay to reduce API bursts. Final status reports total/sent/failed and clickable names for a limited set of failures.
- VK permission failures are reported rather than treated as successful delivery.
