NVIDIA NIM — команды V68 без ручной подстановки моделей
======================================================

Главная команда
---------------
Гигорейв api nvidia полный тест

Она сама:
1. проверит NVIDIA_API_KEY через GET /models;
2. получит каталог;
3. переберёт до 30 chat/instruct-моделей;
4. пропустит модели с account-specific HTTP 404;
5. найдёт первую реально рабочую модель;
6. прогонит пять готовых тестов;
7. покажет model id, HTTP-коды, время и ответы.

Диагностика
-----------
GET /models HTTP 200 означает: ключ принят.
POST /chat/completions HTTP 404 Function not found for account означает: эта конкретная модель не назначена аккаунту.
HTTP 401/403 означает проблему авторизации или разрешений.
HTTP 429 означает квоту или rate limit.
