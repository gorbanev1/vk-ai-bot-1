Gigorave V156
=============

1. Распакуйте full-архив поверх новой папки либо примените patch V155 -> V156 поверх рабочей V155.
2. Сохраните свой `.env` и рабочие данные/постоянную auto-summary SQLite.
3. Запустите `npm install`, если зависимости ещё не установлены.
4. Запустите `npm run verify` при необходимости.
5. Запустите бота обычной командой `npm start`.

Проверка функции:
    Гигорейв досье <имя>

Ожидается: никакого запроса пароля; команда доступна обычному участнику групповой беседы; итоговое досье помещается в одно сообщение и не превышает 2800 символов.
