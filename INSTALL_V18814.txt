Gigorave V188.14 installation

1. Stop the bot.
2. Back up the current project and runtime data/SQLite files.
3. Replace application sources with the V188.14 full-sources archive, preserving your
   own `.env`, `data/`, browser profile and other runtime state.
4. Install dependencies if needed: `pnpm install`.
5. Run: `pnpm run test:v18814`.
6. Optional full static verification: `pnpm run check:syntax && pnpm run check:imports && pnpm run check:named-imports`.
7. Start the bot.

------------
A. Enter "Предложить тусу", create/leave a draft in review, then send another VK post
   URL. Console must show `[EVENT PROPOSAL NEW SOURCE RESTART]`, followed by normal
   parser trace logs. The bot must not answer "Не понял правку черновика".
B. Submit the Vavilone/Tupik announcement. The venue must be detected locally.
C. Submit the NO PLACE FOR OLD PADS / DIESEL Bar post. Venue/date/start time/price must
   be extracted; the original poster should be retained for proposal image preparation.
