V61 — DOSSIER FUZZY TARGET + ON-DEMAND BACKFILL

Установка поверх V60:
1. Остановить бота.
2. Сохранить .env и папку data.
3. Распаковать patch-архив V61 поверх каталога проекта с заменой файлов.
4. Выполнить: pnpm install --frozen-lockfile
5. Выполнить: pnpm verify
6. Запустить: pnpm dev

Новых переменных .env, зависимостей и миграций SQLite нет.
Существующая база сохраняется. Пустое досье после правильного пароля может быть построено по уже сохранённым сообщениям участника.
