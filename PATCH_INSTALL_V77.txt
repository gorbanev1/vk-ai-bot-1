V77 — полный состав VK-беседы для команд «доебаться/фас»

1. Остановите бота: Ctrl+C.
2. Распакуйте содержимое VK_AI_BOT_V77_CUMULATIVE_PATCH поверх корня проекта.
3. Не удаляйте и не заменяйте:
   .env
   data/
   data/bot.sqlite
   data/scraper-browser-profile/
4. Выполните:
   pnpm install --frozen-lockfile
   pnpm run test:roast-roster
   pnpm run test:command-routing
   pnpm verify
   pnpm dev

Ожидаемая сборка:
[BOT BUILD] events-v77-roast-full-roster-name-only-fallback

Проверка:
Гигорейв доебаться @timasin228
Гигорейв фас [id123|Имя]
Гигорейв доебаться

В консоли при доступе к составу беседы должна появиться строка:
[ROAST VK ROSTER] peer=... participants=... source=messages.getConversationMembers
