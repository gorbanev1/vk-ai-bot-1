Gigorave V188.37 — true compact party output + single-link diagnostic reparse

1. "тусы ... кратко/коротко" now sends one compact text list only:
   title — date/time — venue — price.
   No descriptions, participant dumps, source lists, ticket links or per-event poster messages.
2. New owner command: "парсер ссылка <URL>" (also "парсер <URL>").
   It reparses only that event source, updates matching existing DB rows and rebuilds the verified snapshot.
3. Single-link reparse diagnostics store full verbatim early/exact and final DOM snapshots,
   trace.jsonl, parser-report.json and run-manifest.json under data/logs/manual-parser/<runId>/.
4. One confirmed poster from one source post is inherited by all event dates from that same post.
   This fixes multi-date announcements such as an opening on both 11 and 12 September.
