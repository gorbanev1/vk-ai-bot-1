V57 — FUZZY PARTICIPANT DATABASE QUESTIONS

Установка поверх V56:
1. Остановить бота.
2. Сохранить свои .env, каталог data/, SQLite-базу и браузерные профили.
3. Наложить содержимое patch-архива поверх каталога V56 с заменой файлов.
4. Выполнить npm install только если зависимости ещё не установлены.
5. Запустить npm run verify.
6. Запустить npm start.

Новых переменных окружения и миграций SQLite нет.
