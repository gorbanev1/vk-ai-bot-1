V72 — NVIDIA Image Progress, Timeout and Fallback

1. Остановить бота Ctrl+C.
2. Скопировать содержимое патча поверх корня проекта с заменой файлов.
3. Не заменять .env и data/.
4. Выполнить:
   pnpm install --frozen-lockfile
   pnpm run test:nvidia-image
   pnpm run test:provider-diagnostics
   pnpm dev

Ожидаемая сборка:
[BOT BUILD] events-v72-nvidia-image-progress-timeout-fallback

Проверка подробного хода запроса:
Гигорейв nvidia графика поток проверить

В консоли появятся START, HEARTBEAT каждые 10 секунд, HEADERS, CHUNK и COMPLETE.
Важно: NVIDIA image endpoint синхронный и не отдаёт SSE-прогресс диффузии. Эти строки показывают реальный жизненный цикл HTTP-запроса и чтение тела ответа.

Необязательно в .env:
NVIDIA_IMAGE_TIMEOUT_MS=600000
