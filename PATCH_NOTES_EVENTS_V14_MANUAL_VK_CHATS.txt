EVENTS V14 — VK-беседы только по ручной команде

1. Автозапуск парсера трёх VK-бесед отключён по умолчанию:
   VK_CHAT_EVENT_AUTOSTART_ENABLED=0.
2. При старте бот больше не открывает беседы, не выполняет первичный обход и не
   запускает часовое сканирование.
3. Новая административная команда:
   «Гигорейв парсер бесед запустить».
   Она открывает все настроенные вкладки без автоматической прокрутки. Видимые
   сообщения анализируются по мере ручного пролистывания.
4. Команда остановки:
   «Гигорейв парсер бесед остановить».
5. «Гигорейв парсер сейчас» обновляет только публичные Telegram/VK-источники.
6. Long Poll не отправляет сообщения бесед в событийный GigaChat, пока ручной
   сеанс не активен.
7. Устранён бесконечный повтор: после ошибки fingerprint сообщения сохраняется
   до конца ручного сеанса, а не удаляется перед следующим DOM-опросом.
8. Двойная запись одной ошибки заменена одной строкой. Объекты ошибок теперь
   сериализуются с message/code/status/response вместо «[object Object]».
