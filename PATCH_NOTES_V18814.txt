Gigorave V188.14 — venue semantics + fresh-source proposal restart

Problems fixed
--------------
1. While an event proposal draft was in `review`, a second VK wall URL was treated as
   a draft correction. The bot replied "Не понял правку черновика" instead of parsing
   the new announcement.
2. Venue extraction was too literal. Phrases such as "встретить утро в Тупике"
   could leave the required venue empty even though the place was explicit by meaning.
3. Venue names printed only on the poster needed to participate in the final venue
   decision when deterministic text parsing was uncertain.
4. The local parser did not recognize `СКОЛЬКО:` as a price label.

What changed
------------
- A new VK/Telegram source URL now has priority over an old proposal review/edit state.
  The old draft is discarded and the new source starts parsing immediately. The bot
  keeps an `awaiting-input` sentinel while parsing so another link can still be sent if
  the new parse fails.
- Added deterministic venue inference that inspects semantic candidates after
  `в` / `во` / `на`, but does not blindly accept every prepositional phrase.
- Added a hard venue catalog with inflection/spelling support for:
  Тупик; Сто Ручьёв; The Last of Vavilone; DIESEL HALL; Rock Bar DIESEL;
  Overlock Bar; Meet Bowling; Паб Мама Анархия.
- Known venue hits are accepted locally, including nearby addresses.
- If required venue is still unresolved, a focused bounded AI audit receives the
  announcement context plus vision-extracted poster facts. It explicitly decides
  whether the material is an event announcement and whether a venue is actually stated.
  `is_event=false` prevents an AI venue from being applied.
- Poster vision remains bounded by the V188.11 proposal limits and cannot retry forever.
- Exact post image URLs continue into proposal image preparation, so the poster is saved
  with the proposal/event instead of being used only as transient OCR/vision evidence.
- `СКОЛЬКО:` is now accepted as a deterministic price label.

Regression examples
-------------------
- `11.09 НОЧНАЯ СМЕНА ... встретить утро в Тупике (Пр-т Революции 31а, Воронеж)`
  -> venue `Тупик, Пр-т Революции 31а, Воронеж`.
- `ГДЕ: DIESEL Bar, ул. Лизюкова, 4 / КОГДА: 19 сентября, двери 18:30, начало 19:00 /
  СКОЛЬКО: 500 рублей`
  -> 2026-09-19, 19:00, DIESEL Bar, ул. Лизюкова, 4, 500 рублей.
- Pending review + `https://vk.ru/wall-240648015_4`
  -> starts a new parse; it is never sent to `parseEventProposalCorrections`.
