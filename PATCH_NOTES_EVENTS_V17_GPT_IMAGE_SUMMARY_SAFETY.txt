Events V17 — GPT image summary safety pipeline

Исправлено:
- команда «резюмируй картинкой» по-прежнему использует только GPT/router.cheap;
- сырые сообщения беседы больше не отправляются напрямую image-модели;
- текстовая GPT-модель сначала формирует короткий безопасный визуальный бриф;
- из брифа удаляются имена, цитаты, ссылки, личные данные и небезопасные темы;
- при policy-refusal image-модели выполняется один повтор с нейтральной абстрактной сценой без людей;
- распознаются отказы провайдера на русском, английском и китайском языках;
- GigaChat в цепочке GPT-картинки не используется.

Опционально:
GPT_IMAGE_PROMPT_MODEL=<text GPT model id>
Если переменная не задана, используется GPT_MODEL_DEFAULT.
