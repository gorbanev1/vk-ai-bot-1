GIGORAVE BOT V148 — INSTALL

1. Остановите текущий бот.
2. Сделайте backup .env и data/bot.sqlite.
3. Распакуйте full V148 поверх отдельной папки проекта либо примените patch V147 → V148.
4. Сохраните свои .env и рабочую data/bot.sqlite; релиз их не содержит.
5. Выполните npm install, если зависимости ещё не установлены.
6. Запустите npm run verify (или минимум npm run check:syntax && npm run check:imports && npm run test:v148).
7. Запустите npm start.

После первого запуска:
- старая зависшая проверка дублей, если она была отмечена running в SQLite, будет помечена interrupted;
- команда «Гигорейв тусы дубли проверить» выполняет быстрый локальный аудит без GPT;
- «Гигорейв тусы дубли статус» показывает результат/состояние;
- «Гигорейв тусы дубли применить» записывает registry, а verified snapshot пересобирает в фоне.
