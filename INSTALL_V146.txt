Gigorave Bot V146

FULL UPDATE
1. Остановить бот.
2. Сохранить свои .env и data/bot.sqlite.
3. Распаковать Gigorave_bot_V146_full.zip поверх отдельной новой папки проекта.
4. Вернуть свой .env и рабочую data/bot.sqlite, если обновляете через новую папку.
5. npm install (если node_modules отсутствует).
6. npm start.

PATCH V145 -> V146
1. Остановить бот.
2. Сделать резервную копию проекта, .env и data/bot.sqlite.
3. Распаковать Gigorave_bot_V146_patch.zip в корень установленного V145 с заменой файлов.
4. npm start.

ПРОВЕРКА ПРОБЛЕМНОГО VK-АНОНСА
Запросите «Тусы» повторно.
